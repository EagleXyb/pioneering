# 桌面端应用 (Electron)

桌面端应用位于 [apps/desktop](file:///d:/Administrator/Desktop/pioneering/apps/desktop)，基于 Electron 42 + React 19 + TypeScript 构建。

## 技术栈

- **运行时**: Electron 42
- **构建工具**: electron-vite 3
- **前端框架**: React 19
- **状态管理**: Zustand 5 + Jotai 2
- **UI 组件**: Radix UI (headless) + Tailwind CSS 4
- **路由**: React Router DOM 7
- **Markdown 渲染**: react-markdown + remark-gfm + rehype-highlight
- **虚拟化**: @tanstack/react-virtual
- **HTTP 客户端**: axios
- **图标**: lucide-react

## 三进程架构

Electron 应用采用标准三进程架构：

```
┌─────────────────────────────────────────────────────────────┐
│                     Main Process (Node.js)                  │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  - 窗口管理（创建/销毁/状态）                        │   │
│  │  - 应用菜单                                          │   │
│  │  - IPC 处理器（白名单）                              │   │
│  │  - 系统交互（文件对话框、shell）                     │   │
│  │  - 安全策略（CSP）                                   │   │
│  └──────────────────────┬──────────────────────────────┘   │
│                         │ IPC (contextBridge)               │
├─────────────────────────┼───────────────────────────────────┤
│                  Preload Script (沙箱)                      │
│  ┌──────────────────────▼──────────────────────────────┐   │
│  │  - contextBridge.exposeInMainWorld()               │   │
│  │  - 仅暴露白名单 API 给渲染进程                       │   │
│  │  - 无 Node.js 直接访问                              │   │
│  └──────────────────────┬──────────────────────────────┘   │
│                         │ window.api                         │
├─────────────────────────┼───────────────────────────────────┤
│                Renderer Process (Chromium)                  │
│  ┌──────────────────────▼──────────────────────────────┐   │
│  │  - React UI 渲染                                    │   │
│  │  - 状态管理 (Zustand/Jotai)                         │   │
│  │  - 通过 window.api 调用主进程能力                    │   │
│  │  - HTTP 请求直接访问后端 API                         │   │
│  │  - sandbox: true, contextIsolation: true            │   │
│  │  - nodeIntegration: false                           │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

## 主进程 (src/main/)

### 入口文件 [index.ts](file:///d:/Administrator/Desktop/pioneering/apps/desktop/src/main/index.ts)

**关键功能：**

1. **安全配置**
   - `sandbox: true`: 启用沙箱，preload 仅能访问受限 API
   - `contextIsolation: true`: 上下文隔离，主/渲染进程上下文分离
   - `nodeIntegration: false`: 渲染进程无 Node.js 访问权限
   - Content-Security-Policy (CSP) 通过 `session.webRequest.onHeadersReceived` 注入

2. **CSP 策略**
   ```
   default-src 'self'
   script-src 'self' ['unsafe-inline' dev only]
   style-src 'self' 'unsafe-inline'
   img-src 'self' data: blob:
   connect-src 'self' http://localhost:9000 ws://localhost:* wss:
   frame-src 'none'; object-src 'none'; base-uri 'none'; form-action 'none'
   ```

3. **窗口创建**
   - 默认尺寸: 1440x900，最小 1024x700
   - 平台适配标题栏（通过 `window-config.ts`）
   - 开发环境加载 Vite dev server URL，生产环境加载本地 HTML

4. **窗口状态事件**
   - `maximize`/`unmaximize`: 推送窗口最大化状态
   - `enter-full-screen`/`leave-full-screen`: 推送全屏状态
   - `setWindowOpenHandler`: 外链通过 shell.openExternal 打开

5. **外部链接处理**: 所有新窗口请求通过系统默认浏览器打开

### IPC 处理器 [ipc-handlers.ts](file:///d:/Administrator/Desktop/pioneering/apps/desktop/src/main/ipc-handlers.ts)

注册所有主进程处理函数，通过 IPC 通道与渲染进程通信。

### 菜单 [menu.ts](file:///d:/Administrator/Desktop/pioneering/apps/desktop/src/main/menu.ts)

- 构建跨平台应用菜单
- macOS: 菜单挂到屏幕顶部（应用内无菜单栏）
- Windows/Linux: 标准窗口菜单

### 窗口配置 [window-config.ts](file:///d:/Administrator/Desktop/pioneering/apps/desktop/src/main/window-config.ts)

- macOS: `titleBarStyle: 'hiddenInset'`（红绿灯控件内联）
- Windows/Linux: `frame: true`（标准标题栏）

## Preload 桥接层 (src/preload/)

### [index.ts](file:///d:/Administrator/Desktop/pioneering/apps/desktop/src/preload/index.ts)

通过 `contextBridge.exposeInMainWorld` 向渲染进程暴露受控 API：

```typescript
// 示例结构（具体API见ipc-channels.ts）
window.api = {
  // 窗口控制
  window: { minimize, maximize, close, isMaximized },
  // 文件操作
  dialog: { openFile, openFolder, saveFile },
  // 系统
  system: { getPlatform, getVersion },
  // 事件监听
  on: (channel, callback) => { ... },
  // ...
}
```

**安全原则：**
- 从不直接暴露整个 ipcRenderer
- 所有通道通过 `ipc-channels.ts` 常量定义
- 渲染进程无法直接访问 Node.js API

### IPC 通道 [ipc-channels.ts](file:///d:/Administrator/Desktop/pioneering/apps/desktop/src/shared/ipc-channels.ts)

定义所有 IPC 通道名称常量，避免硬编码字符串：

```typescript
export enum IpcChannel {
  WINDOW_MINIMIZE = 'window:minimize',
  WINDOW_MAXIMIZE = 'window:maximize',
  WINDOW_CLOSE = 'window:close',
  WINDOW_STATE_CHANGED = 'window:state-changed',
  WINDOW_FULLSCREEN_CHANGED = 'window:fullscreen-changed',
  DIALOG_OPEN_FILE = 'dialog:open-file',
  DIALOG_OPEN_FOLDER = 'dialog:open-folder',
  // ...
}
```

## 安全设计总结

| 安全措施 | 配置 | 作用 |
|----------|------|------|
| 沙箱模式 | `sandbox: true` | 渲染进程在 Chromium 沙箱中运行 |
| 上下文隔离 | `contextIsolation: true` | 主/渲染进程上下文完全分离 |
| Node 集成关闭 | `nodeIntegration: false` | 渲染进程无法直接访问 Node.js API |
| Preload 白名单 | `contextBridge` 仅暴露受控 API | 最小权限原则 |
| Content Security Policy | 严格 CSP 头 | 防止 XSS 执行内联脚本/加载未知资源 |
| 外链处理 | `shell.openExternal` | 新窗口由系统浏览器打开 |
| IPC 通道常量 | 集中定义 `IpcChannel` 枚举 | 避免通道名硬编码，便于审计 |

## 开发与构建命令

```bash
# 开发模式（热重载）
npm run dev

# 类型检查
npm run typecheck
npm run typecheck:node  # 仅检查主进程
npm run typecheck:web   # 仅检查渲染进程

# 代码格式化
npm run format

# 构建
npm run build
npm run build:unpack    # 构建但不打包
npm run build:win       # Windows 安装包 (NSIS)
npm run build:mac       # macOS 安装包 (DMG)
npm run build:linux     # Linux 安装包 (AppImage)
```
