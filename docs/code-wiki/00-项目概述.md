# Pioneering - 项目概述

## 项目简介

Pioneering 是一个企业级模块化 AI Agent 平台，提供多模态感知、LLM 推理、工具调用、长期记忆与持续进化能力。项目采用 Monorepo 架构，包含后端核心框架、API 服务、桌面端应用、Web 端应用以及营销页面。

## 核心特性

- **模块化 Agent 框架 (ModuAgent)**：基于 LangGraph 图编排，支持可插拔组件
- **多模态感知**：支持文本、图像、音频输入处理
- **多模型支持**：DeepSeek、GPT、Qwen、GLM 等多种 LLM 提供商
- **工具系统**：内置计算器、代码执行、文件操作、HTTP 请求、搜索、SQL 查询等工具
- **记忆系统**：短期缓存 + 长期向量存储（ChromaDB）
- **反馈进化闭环**：质量评估 → 进化信号 → 参数调优 → 版本回滚
- **多 Agent 协作**：Supervisor + Subagent 模式，支持共识机制
- **Human-in-the-Loop**：敏感工具调用人工审批
- **可观测性**：结构化日志、Metrics 指标、分布式 Tracing
- **多端支持**：桌面端 (Electron)、Web 端 (React)、营销页 (Next.js)

## 技术栈

### 后端
- **语言**：Python 3.11+
- **Web 框架**：FastAPI
- **Agent 编排**：LangGraph
- **LLM 集成**：LangChain
- **向量存储**：ChromaDB
- **数据库**：PostgreSQL (asyncpg)
- **HTTP 客户端**：httpx

### 前端
- **框架**：React 19 / React 18
- **构建工具**：Vite / Electron Vite
- **状态管理**：Zustand / Jotai
- **UI 组件**：Radix UI / TDesign React
- **样式**：Tailwind CSS 4
- **路由**：React Router 7

### 桌面端
- **框架**：Electron 42
- **安全特性**：沙箱模式、Context Isolation、CSP 策略

### 营销页
- **框架**：Next.js 15
- **样式**：Tailwind CSS
- **动画**：Framer Motion (自定义动画组件)

## 快速开始

详细的运行指南请参考 [09-开发指南.md](09-开发指南.md)。

### 环境要求

- Python >= 3.11
- Node.js >= 18
- npm >= 9
- PostgreSQL（可选，默认无数据库模式启动）

### 一键启动（Windows）

```powershell
# 启动所有服务（后端 + Web + 营销页）
.\start.ps1
```

### 手动启动

**后端：**
```bash
cd apps/backend
# 创建虚拟环境并安装依赖
python -m venv venv
.\venv\Scripts\activate
pip install -e ./ModuAgent[dev]
pip install -e .
# 启动服务
uvicorn app.main:app --host 0.0.0.0 --port 9000 --reload
```

**Web 前端：**
```bash
cd apps/web
npm install
npm run dev
```

**桌面端：**
```bash
cd apps/desktop
npm install
npm run dev
```

**营销页：**
```bash
cd apps/marketing
npm install
npm run dev
```
