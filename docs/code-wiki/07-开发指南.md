# 开发指南

## 环境准备

### 必需软件

| 软件 | 最低版本 | 说明 |
|------|----------|------|
| Python | 3.11+ | 后端运行时 |
| Node.js | 18+ | 前端构建运行时 |
| npm | 9+ | Node 包管理器 |
| Git | 任意 | 版本控制 |
| PostgreSQL | 14+ | 数据库（可选，无数据库模式可启动） |

### 推荐工具

- **VS Code** 或 **Trae IDE**：推荐 IDE
- **Python 扩展**：Python 语言支持
- **ESLint/Prettier**：前端代码规范
- **Ruff**：Python 代码检查（项目已配置）
- **mypy**：Python 类型检查（项目已配置）

## 首次搭建

### 1. 克隆项目

```bash
git clone <repository-url>
cd pioneering
```

### 2. 后端环境搭建

```bash
cd apps/backend

# 创建 Python 虚拟环境
python -m venv venv

# 激活虚拟环境
# Windows (PowerShell):
.\venv\Scripts\Activate.ps1
# Windows (CMD):
.\venv\Scripts\activate.bat
# Linux/Mac:
source venv/bin/activate

# 安装 ModuAgent（开发模式）
pip install -e ./ModuAgent[dev]

# 安装后端应用依赖
pip install -e .
```

### 3. 前端环境搭建

**Web 前端：**
```bash
cd apps/web
npm install
```

**桌面端：**
```bash
cd apps/desktop
npm install
```

**营销页：**
```bash
cd apps/marketing
npm install
```

### 4. 环境配置

复制环境变量模板：

```bash
cd apps/backend
copy .env.example .env
```

编辑 `.env` 文件，配置必要项：
- `LLM_API_KEY`: 你的 LLM API Key
- `LLM_BASE_URL`: API 地址（默认 DeepSeek）
- `JWT_SECRET`: 生产环境务必修改为随机字符串

**数据库配置（可选）：**
- 如不配置 PostgreSQL，后端将以无数据库模式启动（登录注册等功能不可用，但 Agent 对话正常）

## 本地开发

### 一键启动（Windows）

项目根目录提供 `start.ps1` 脚本，一键启动后端 + Web 前端 + 营销页：

```powershell
# 在项目根目录执行
.\start.ps1
```

启动后访问：
- 后端 API: http://localhost:9000
- API 文档: http://localhost:9000/docs
- Web 前端: http://localhost:5173
- 营销页: http://localhost:9001

脚本会自动停止已有服务、创建日志目录、后台启动各进程，并在 `logs/` 目录下记录日志。

### 手动启动（推荐开发调试）

**启动后端（终端 1）：**
```bash
cd apps/backend
.\venv\Scripts\Activate.ps1  # Windows
uvicorn app.main:app --host 0.0.0.0 --port 9000 --reload
```

`--reload` 参数开启热重载，代码修改后自动重启。

**启动 Web 前端（终端 2）：**
```bash
cd apps/web
npm run dev
```

访问 http://localhost:5173

**启动桌面端（终端 2，替代 Web 前端）：**
```bash
cd apps/desktop
npm run dev
```

Electron 窗口将自动打开，支持热重载。

**启动营销页（终端 3，可选）：**
```bash
cd apps/marketing
npm run dev
```

访问 http://localhost:9001

## 代码规范

### Python 代码规范

项目使用以下工具保证代码质量（见 [pyproject.toml](file:///d:/Administrator/Desktop/pioneering/apps/backend/ModuAgent/pyproject.toml)）：

- **Ruff**: Linting + import 排序
  - 行长度: 120
  - 规则: E, F, I, N, W, UP
- **mypy**: 类型检查
  - Python 版本: 3.11
  - `warn_return_any = true`
  - `disallow_untyped_defs = true`

```bash
# 代码检查
cd apps/backend/ModuAgent
ruff check .
ruff format .

# 类型检查
mypy .
```

#### Python 代码风格

- 使用类型注解（mypy 强制）
- 所有公共函数/类必须有 docstring
- 遵循 PEP 8 命名规范
- 异常处理需具体，禁止裸 `except:`
- 异步代码使用 `async/await`，避免阻塞调用

### TypeScript/React 代码规范

- 使用 TypeScript 严格模式
- 桌面端使用 Prettier 格式化：`npm run format`
- 组件使用函数式组件 + Hooks
- 状态管理优先使用 Zustand/Jotai
- UI 组件优先复用 Radix UI 基础组件封装

## 常见问题

### 1. 后端启动报错缺少依赖

确保在虚拟环境中安装了所有依赖：
```bash
pip install -e ./ModuAgent[dev]
pip install -e .
```

### 2. ChromaDB 初始化失败

ChromaDB 需要 SQLite 支持。如遇错误，系统会自动降级为内存存储（InMemoryStoreAdapter），不影响基础功能。可通过配置 `memory.store_type: "in_memory"` 强制使用内存存储。

### 3. LLM 调用失败

- 检查 `LLM_API_KEY` 是否配置正确
- 检查 `LLM_BASE_URL` 是否可访问
- 查看日志：`logs/backend/agent.log`

### 4. 前端连接后端失败

- 确认后端已启动（http://localhost:9000/docs 可访问）
- 检查 CORS 配置：后端 `CORS_ORIGINS` 需包含前端地址
- 桌面端检查 CSP `connect-src` 配置

### 5. 桌面端白屏

- 开发环境检查 Vite dev server 是否正常
- 检查 CSP 是否阻止了脚本加载（开发环境需要 `'unsafe-inline'`）
- 打开 DevTools（Ctrl+Shift+I）查看控制台错误

### 6. 数据库连接失败

这是正常情况——如未配置 PostgreSQL，后端会以无数据库模式启动：
- Agent 对话功能正常
- 用户登录/注册、会话持久化功能不可用
- 日志会显示 "数据库连接失败，服务将以无数据库模式启动"

## 调试技巧

### 后端调试

1. **查看日志**: `logs/backend/agent.log` 包含详细日志
2. **使用 pdb/breakpoint()**: 在代码中插入断点
3. **LangGraph 可视化**: LangGraph 支持 `.get_graph().draw_mermaid_png()` 生成图可视化
4. **API 调试**: 访问 http://localhost:9000/docs 使用 Swagger UI 直接测试接口

### 前端调试

1. **React DevTools**: 浏览器/DevTools 扩展，查看组件树和状态
2. **Network 面板**: 查看 SSE 事件流和 API 请求
3. **桌面端 DevTools**: 按 Ctrl+Shift+I 打开

### SSE 流式响应调试

在浏览器 DevTools Network 面板找到 agent/stream 请求，在 EventStream 标签查看实时 AG-UI 事件：
- `THINKING_*`: 思考过程
- `TEXT_MESSAGE_*`: 文本响应
- `TOOL_CALL_*`: 工具调用
- `RUN_ERROR`: 错误事件

```bash

pip install -e ./ModuAgent
pip install -e .

uvicorn app.main:app --host 0.0.0.0 --port 9000 --workers 4
```

