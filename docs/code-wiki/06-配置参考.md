# 配置参考

## 后端配置

### 应用配置 (app/config.py)

通过环境变量或 `.env` 文件配置，位于 [apps/backend/app/config.py](file:///d:/Administrator/Desktop/pioneering/apps/backend/app/config.py)。

| 环境变量 | 类型 | 默认值 | 说明 |
|----------|------|--------|------|
| `DATABASE_URL` | string | `postgresql+asyncpg://postgres:root@localhost:5432/pioneering` | PostgreSQL 连接串 |
| `JWT_SECRET` | string | `default-secret-change-in-production` | JWT 签名密钥（生产必须修改） |
| `JWT_EXPIRATION_HOURS` | int | `2` | Access Token 有效期（小时） |
| `REFRESH_TOKEN_EXPIRATION_DAYS` | int | `30` | Refresh Token 有效期（天） |
| `LLM_API_KEY` | string | `""` | LLM API Key |
| `LLM_BASE_URL` | string | `https://api.deepseek.com/v1` | LLM API 地址 |
| `LLM_DEFAULT_MODEL` | string | `deepseek-v4-flash` | 默认模型 |
| `HOST` | string | `0.0.0.0` | 监听地址 |
| `PORT` | int | `9000` | 监听端口 |
| `CORS_ORIGINS` | string | `http://localhost:5173,http://localhost:3000` | CORS 允许来源（逗号分隔） |
| `UPLOAD_DIR` | string | `./uploads` | 上传文件目录 |
| `MAX_UPLOAD_SIZE` | int | `10485760` | 最大上传大小（字节，默认 10MB） |
| `LOG_DIR` | string | `./logs` | 日志目录 |

### ModuAgent 运行时配置

位于 [apps/backend/ModuAgent/config/runtime_config.py](file:///d:/Administrator/Desktop/pioneering/apps/backend/ModuAgent/config/runtime_config.py)，支持环境变量 `MODU_*` 和 JSON 配置文件。

#### LLM 配置

| 配置路径 | 环境变量 | 默认值 | 说明 |
|----------|----------|--------|------|
| `llm.default_provider` | `MODU_LLM_PROVIDER` | `deepseek` | 默认 LLM 提供商 |
| `llm.temperature` | `MODU_LLM_TEMPERATURE` | `0.7` | 温度参数 |
| `llm.max_tokens` | `MODU_LLM_MAX_TOKENS` | `512` | 最大生成 token 数 |
| `llm.max_reasoning_iterations` | - | `3` | ReAct 循环最大迭代次数 |
| `llm.max_format_retries` | - | `2` | 格式错误最大重试次数 |
| `llm.retry.max_attempts` | - | `2` | LLM 调用最大重试次数（含首次） |

#### 记忆配置

| 配置路径 | 默认值 | 说明 |
|----------|--------|------|
| `memory.default_strategy` | `cache` | 默认记忆策略 |
| `memory.context_window` | `last_5_turns` | 上下文窗口大小 |
| `memory.checkpointer_type` | `memory` | 检查点类型：`memory`/`sqlite`/`none` |
| `memory.store_type` | `chroma` | 长期存储类型：`chroma`/`in_memory`/`none` |
| `memory.chroma_persist_path` | `None` | ChromaDB 持久化路径（None=内存模式） |

| 配置路径 | 默认值 | 说明 |

| `tools.retry.base_delay` | `0.5` | 指数退避基础延迟（秒） |

#### 感知配置

| 配置路径 | 默认值 | 说明 |
|----------|--------|------|
| `perception.default_processor` | `text_preprocessor` | 默认感知器 |
| `perception.max_length` | `2048` | 最大输入长度 |
| `perception.sensitivity_threshold` | `5` | 敏感度熔断阈值（0-5） |
| `perception.security.enable_guard` | `True` | 启用安全检测 |
| `perception.security.block_on_injection` | `False` | 检测到注入时直接拒绝 |
| `perception.security.block_on_pii` | `False` | 检测到 PII 时直接拒绝 |

#### 感知管线路由

```yaml
perception:
  routing:
    text:
      pipeline: ["text_preprocessor", "llm_parser"]
    image:
      pipeline: ["image_processor", "text_preprocessor"]
    audio:
      pipeline: ["audio_processor", "text_preprocessor"]
  fusion:
    strategy: weighted_average  # weighted_average | max_confidence | voting
    weights:
      text: 0.5
      image: 0.3
      audio: 0.2
```

## 日志配置

### 后端日志

- 日志目录：`logs/backend/`
- 日志文件：`agent.log`
- 轮转策略：按日轮转（`midnight`），保留 30 天
- 日志格式：`%(asctime)s | %(levelname)-8s | %(name)s | %(message)s`

### 启动脚本日志

各服务日志重定向到：
- 后端：`logs/backend/uvicorn.log`
- 前端：`logs/frontend/vite.log`
- 营销页：`logs/marketing/nextjs.log`

### 感知事件日志

- 路径：`logs/perception_events.jsonl`（可配置）
- 格式：JSON Lines
- 轮转：按大小（默认 10MB）
