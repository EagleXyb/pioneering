## 核心数据流

### 单次请求流程

```
用户输入
   │
   ▼
[1] 感知层 (Perception)
   ├─ 输入路由（text/image/audio）
   ├─ 感知器链执行
   ├─ 安全检测（注入/PII/敏感度）
   ├─ 多路结果融合
   └─ 敏感度熔断检查 → 熔断则直接响应
   │
   ▼
[2] 记忆查询 (Memory Query)
   ├─ 短期记忆（Checkpointer 自动管理）
   └─ 长期记忆（向量检索）
   │
   ▼
[3] 推理层 (Reasoning) ──┐
   ├─ LLM 调用           │
   ├─ Function Calling   │ ReAct 循环
   └─ 工具调用判断 ←──────┘
   │
   ├─ [HITL] 人工审批（敏感工具）
   │
   ▼
[4] 工具执行 (Action)
   └─ 工具结果处理
   │
   ▼
[5] 响应生成 (Response)
   │
   ▼
[6] 反馈评估 (Feedback)
   ├─ 质量评估（规则/LLM-as-Judge）
   └─ 进化信号收集
   │
   ▼
[7] 记忆更新 (Memory Update)
   └─ 写入长期记忆
   │
   ▼
[8] 进化触发（条件满足时）
   ├─ 参数调优
   └─ 组件替换
```

## 分层架构说明

### 1. 客户端层

| 应用 | 技术栈 | 主要职责 |
|------|--------|----------|
| Desktop | Electron + React 19 + Zustand + Jotai | 桌面原生体验，本地文件访问，系统集成 |
| Web | React 18 + TDesign + Zustand | 浏览器端访问，三种交互模式（Chat/Pro/Task） |
| Marketing | Next.js 15 + Tailwind CSS | 产品展示，营销落地页 |

### 2. API 层

FastAPI 提供 RESTful API 和 SSE 流式接口：

- **认证模块** (`/api/v1/auth`)：JWT 登录注册
- **聊天模块** (`/api/v1/chat`)：基础对话接口
- **Agent 模块** (`/api/v1/agent`)：Agent 流式对话（AG-UI 协议）
- **用户模块** (`/api/v1/user`)：用户管理
- **系统模块** (`/api/v1/system`)：系统配置与状态
- **上传模块** (`/api/v1/upload`)：文件上传

所有非 SSE 响应统一包装为 `{ code, data, message }` 格式。

### 3. Agent Bridge 层

[agent_bridge.py](file:///d:/Administrator/Desktop/pioneering/apps/backend/app/core/agent_bridge.py) 是 API 层与 ModuAgent 核心之间的桥梁：

- **组件初始化**：注册默认感知器、推理引擎、工具、记忆组件
- **流式转换**：将 LangGraph 事件转换为 AG-UI 标准 SSE 事件
- **元数据收集**：StreamContext 收集 token 用量、延迟、工具执行等信息
- **模型切换**：支持运行时模型覆盖

### 4. ModuAgent 核心层

#### 感知层 (components/perception/)
- 支持文本、图像、音频多模态输入
- 可配置感知器管线（pipeline）
- 内置安全检测：Prompt 注入、PII、敏感内容
- 多路感知结果融合策略（加权平均/最大置信度/投票）

#### 推理层 (components/reasoning/)
- 统一 LLM 接口，支持多提供商
- DeepSeek / GPT / Qwen / GLM 适配器
- 符号推理引擎（规则引擎）
- 自动重试与降级策略

#### 行动层 (components/action/)
- 工具抽象基类，统一接口
- 同步/异步执行器
- 内置工具集：
  - `calculator`：数学计算
  - `code_executor`：代码执行
  - `datetime_tool`：日期时间
  - `file_ops`：文件操作
  - `http_request`：HTTP 请求
  - `search`：网络搜索
  - `sql_query`：SQL 查询
- 工具级重试与超时控制

#### 记忆层 (components/memory/)
- 短期记忆：LangGraph Checkpointer（内存/SQLite）
- 长期记忆：ChromaDB 向量存储
- 语义检索与上下文窗口管理

### 5. 编排层 (modu_graph/)

基于 LangGraph StateGraph 的图编排引擎：

- **状态定义**：[ModuAgentState](file:///d:/Administrator/Desktop/pioneering/apps/backend/ModuAgent/modu_graph/state.py#L47-L155) - 类型化的图状态
- **节点定义**：[nodes.py](file:///d:/Administrator/Desktop/pioneering/apps/backend/ModuAgent/modu_graph/nodes.py) - 各功能节点
- **图构建**：[graph.py](file:///d:/Administrator/Desktop/pioneering/apps/backend/ModuAgent/modu_graph/graph.py#L89-L318) - 图结构与条件路由
- **工厂类**：[factory.py](file:///d:/Administrator/Desktop/pioneering/apps/backend/ModuAgent/modu_graph/factory.py#L154-L287) - 配置化组件创建
- **运行器**：[runner.py](file:///d:/Administrator/Desktop/pioneering/apps/backend/ModuAgent/modu_graph/runner.py) - 流式/非流式执行入口

#### 图节点结构

```
START → perception → [route_after_perception]
                         ├─ 熔断 → response → feedback → memory_update → END
                         └─ 正常 → memory_query
                                      │
                                      ├─ 单 Agent: agent → [route_after_agent]
                                      │                   ├─ 有工具 → human_review(可选) → tools → agent
                                      │                   └─ 无工具 → response
                                      │
                                      └─ 多 Agent: supervisor → subagent_run(并行) → consensus → response
```

### 6. 反馈进化层

- **质量监控** (feedback/quality_monitor.py)：规则/LLM/混合三种模式
- **反馈循环** (feedback/loop_controller.py)：评估输出质量，判断是否需要进化
- **信号收集** (feedback/evolution_signal.py)：收集多维度进化信号
- **进化编排** (evolution/evolution_orchestrator.py)：协调评估与策略执行
- **参数调优** (evolution/strategy/parameter_tune.py)：动态调整 LLM 参数
- **版本管理** (evolution/registry/versioned_store.py)：组件版本化存储
- **回滚机制** (evolution/registry/rollback_mechanism.py)：质量下降时自动回滚

### 7. 多 Agent 协作 (orchestration/)

- **消息总线** (communication/message_bus.py)：Agent 间事件通信
- **协议定义** (communication/protocol.py)：标准化事件格式
- **Supervisor 模式** (modu_graph/subgraph/supervisor.py)：任务拆分与分发
- **共识机制** (patterns/consensus.py)：多数投票/加权/LLM 裁决

### 8. 可观测性 (observability/)

- **结构化日志**：JSON 格式日志输出
- **Metrics 指标**：Prometheus 格式（请求计数、延迟、错误率）
- **分布式追踪**：OpenTelemetry 集成
- **链路上下文**：trace_id 贯穿全流程

## 关键设计模式

### 1. 插件化架构

通过 [ComponentRegistry](file:///d:/Administrator/Desktop/pioneering/apps/backend/ModuAgent/core/registry.py#L16-L197) 实现组件动态注册与替换：

- 所有组件遵循核心接口（ABC 抽象基类）
- 运行时可注册新组件或替换现有组件
- 首个注册的组件为默认实现
- 支持显式设置活跃组件

### 2. 配置驱动

[RuntimeConfig](file:///d:/Administrator/Desktop/pioneering/apps/backend/ModuAgent/config/runtime_config.py) 提供分层配置：

- 默认配置 → 配置文件 → 环境变量 → 运行时覆盖
- 配置变更回调机制，关键配置变更时自动重建图
- 配置哈希缓存，避免重复构建图

### 3. 异步流式处理

- 全链路异步（async/await）
- 感知器并行执行（P2-12.2.4）
- Token 级流式输出
- SSE 实时推送事件

### 4. 安全设计

**桌面端安全**：
- 沙箱模式 (`sandbox: true`)
- 上下文隔离 (`contextIsolation: true`)
- Node 集成关闭 (`nodeIntegration: false`)
- Content-Security-Policy (CSP)
- Preload 桥接层（白名单 IPC）

**后端安全**：
- 感知层安全检测（注入/PII/敏感词）
- JWT 认证
- CORS 配置
- 文件上传限制
- 工具调用人工审批（HITL）
