## 1. 背景与目标

产品同时存在两套对外叙事：官网把自己描述为“不替你下判断，让你看清自己是怎么下判断的**认知陪练智能体**”；产品内的“关于”则写的是“**创路 Agent · 多模态智能工作台**”。代码实现更接近后者：三模式对话、工具执行、过程可视化、产物生成与多端接入。

> **定位差异（需产品决策）**：官网强调认知训练与方法论溯源（先问后答、知识溯源、反问收尾），实现侧强调工作任务完成（分析、任务、文档产物）。本 PRD 以“可执行产品现状”为主，官网叙事作为品牌层单列，两者是否需要收敛见第 7 节。

从现有实现可以确认的产品目标：让用户在同一个产品内完成从“提出模糊问题”到“得到可追溯结果”的闭环——可以只是对话，也可以是带工具执行的分析，或先确认计划再执行的任务；过程可见、关键动作可人工确认、结果可复制与留档。

| 要解决的问题 | 产品回应 |
|---|---|
| 长流程 Agent 的黑盒感、不可中断、不可纠错；不同任务强度缺少分层入口；云端与离线场景割裂 | 三模式分层、过程容器与执行轨迹、HITL 暂停确认、编辑重发与重新生成、双端 + 本地运行时 |

## 2. 产品范围与角色

### 2.1 端与范围

| 端 | 定位 | 现状 |
|---|---|---|
| Web（apps/web） | 浏览器内的主产品：聊天 / 分析 / 任务 / 插件市场 / 设置 | `[已实现]` |
| Desktop（apps/desktop） | 桌面客户端：同一套三模式能力 + 本地运行时 + 快捷键 + 系统集成 | `[已实现]`，部分页面占位 |
| Backend（apps/backend-ts） | 账户、会话、Agent 执行、模型网关、配额、管理面 | `[已实现]` |
| Agent 内核（packages） | 执行编排、工具、技能、MCP、场景包与流式事件 | `[已实现]` |
| Marketing（apps/marketing） | 品牌官网：首页 / 智能体 / 认知 / 案例 / 洞察 / 关于 / 趋势 | `[已实现]`（演示内容为静态） |
| Mobile（apps/mobile） | 移动端 | `[占位]`，空目录 |

### 2.2 角色

| 角色 | 定义 |
|---|---|
| 访客 | 浏览官网、查看静态对话演示；不能进入产品工作台。 |
| 普通用户 | 注册/登录后拥有个人会话、消息、配额与设置；数据按用户隔离。 |
| 本地单用户 | 桌面端在无后端/离线时以固定本地身份工作，不经过登录；会话与消息保存在本地。 |
| 管理员 | 由部署配置指定；可查看用户列表、修改技能白名单、访问可观测与成本数据。 |

### 2.3 范围边界

- **P0（本次基线覆盖）**：登录进入 → 发起一种模式 → 流式获得结果 / 完成人工确认 → 得到回答或产物 → 可编辑、重试、归档。
- **P1（已存在但非核心闭环）**：插件·技能市场、MCP 连接、用量与成本、归档会话、快捷键、主题与字号。
- **明确未交付**：移动端、桌面“助理/我的文件/更多/空间”、自动化后端调度、桌面插件真实安装、收藏夹/官网/下载电脑版入口、隐私模式、桌面通知与提示音、多语言。

## 3. 产品模型与核心流程

### 3.1 核心对象

| 对象 | 定义 | 关键属性（产品语义） |
|---|---|---|
| 会话 | 一次连续对话的容器，分为普通聊天与 Agent 会话 | 模式（无 / ReAct / Plan-Execute）、运行时（云端 / 本地）、归属用户、归档状态、消息数 |
| 消息 | 会话中的一条用户或助手内容 | 角色、正文、过程块（思考 / 工具 / 叙述）、反馈、token 用量、模型 |
| 执行轨迹 | 一次 Agent 执行的可视化过程记录 | 节点（思考 / 工具调用 / 观察 / 计划步骤）、耗时、状态、token |
| HITL 项 | 需要用户确认或回答才能继续的暂停点 | 类型、所属会话与执行、选项/工具信息、有效期 |
| 产物 | Agent 生成的文档或可预览结果 | 标题、内容、来源消息、文件位置 |
| 技能 / 插件 | 可被 Agent 调用的能力单元或外部服务 | 启用状态、工具数、连接状态、冲突提示 |
| 用量 | 用户 token 消耗与配额 | 日配额、已用、重置时间、按模型计价 |

### 3.2 模式映射（固定约定）

| 入口 | 会话类型 | 执行方式 | 用户心智 |
|---|---|---|---|
| Web `/chat` / 桌面默认对话 | 普通聊天 | 不进入 Agent 执行流程 | 快速问答、搜索、文档写作 |
| Web `/pro`（智能分析） | Agent 会话 | ReAct 执行 | 边想边做，工具执行过程可见，可人工确认 |
| Web `/task`（任务） | Agent 会话 | 先计划后执行 | 先出计划、确认后逐步执行 |
| 桌面 Agent 模式 | Agent 会话（云端或本地） | 沿用会话创建时的执行方式 | 与 Web 分析 / 任务一致；本地离线可用 |

### 3.3 核心旅程

登录 / 本地身份 → 选择模式并新建会话 → 输入问题 / 附件 → 流式输出与过程 → 必要时人工确认 → 回答 / 产物 → 编辑重发 / 重试 / 反馈 / 归档。

## 4. 功能需求

按用户任务组织。每条需求包含目的、触发、处理规则、结果与状态、异常与边界；跨模块共享规则在第 5 节统一定义，功能章节不再重复。

### 4.1 账户与身份

#### FR-ACC-01 注册、登录与会话保持

- **目的**：让用户建立可被隔离的个人空间，并在多次访问间保持登录态。
- **触发**：首次访问受保护页面，或主动进入登录 / 注册页。
- **规则**：支持账号密码注册与登录；浏览器端在访问令牌过期时自动刷新，刷新失败则清空登录态并回到登录页；桌面端登录态保存在本地安全存储中，重启后恢复。
- **结果**：登录后进入上次使用的模式页；未登录访问工作台会被拦截到登录页。
- **异常**：账号或密码错误直接提示，不触发自动刷新；网络故障保留本地缓存并标记可重试，不误判为“未登录”。

#### FR-ACC-02 个人资料与退出

- **触发**：账户弹层 / 设置-账户分区。
- **规则**：展示昵称、用户名、邮箱、手机号、注册时间与用户 ID；支持刷新资料与复制关键字段；退出登录需二次确认，退出后清除令牌并回到未登录态。
- **结果**：资料更新即时反映在侧边栏账户区；退出后不再能读写个人会话。
- **状态**：`[已实现]`（云端）；本地单用户不显示登录入口。

#### FR-ACC-03 找回密码 / 微信登录

- **现状**：Web 提供找回密码页面；后端提供小程序与网页微信登录能力。`[TBD]`：微信登录在产品内是否有可见入口、找回密码是否真实发送凭证，需产品确认。
- **规则（若有）**：找回流程必须可验证身份且不泄露账号是否存在；微信登录需完成账号绑定合并策略（见开放问题）。

### 4.2 对话模式

#### FR-MODE-01 普通聊天（Chat）

- **目的**：低成本、低门槛的问答与写作，支持搜索增强、深度思考与引用来源。
- **触发**：Web `/chat` 或桌面默认对话；首次发送自动创建会话。
- **规则**：可选“深度思考”与“联网搜索”；可指定模型；支持图片与文件附件；回答以流式输出；可在回答后查看参考来源面板。
- **结果**：会话与消息持久化；首条消息后会话标题自动生成；回答支持复制、点赞/点踩、分享、重新生成。
- **异常**：流式超时、网络断开可重试；服务端错误以可读文案提示；停止生成保留已产出内容。

#### FR-MODE-02 智能分析（Pro / ReAct）

- **目的**：面对需要检索、计算、写作的复杂问题，展示 Agent 的推理与工具过程，并在关键动作前请求确认。
- **触发**：Web `/pro`；桌面在 Agent 模式下发起分析。
- **规则**：使用 ReAct 执行；过程块（思考 / 工具调用 / 叙述）统一收进可折叠“过程容器”；运行中展开并计时，完成后收起为一行摘要；工具连续同类调用聚合为批次行；右侧提供推理过程 / 执行轨迹面板。
- **结果**：最终回答与过程分离；操作栏提供复制、赞/踩、分享、重新生成与 token 用量；可生成文档产物。
- **异常**：工具上限或中止后无最终回答时展示兜底提示，而不是空白消息；暂停等待人工确认时保留半截消息并显示状态。

#### FR-MODE-03 任务（Task / Plan-Execute）

- **目的**：把复杂目标拆成可确认的计划，再逐步执行，适合多步骤研究与交付。
- **触发**：Web `/task`；桌面任务入口。
- **规则**：先生成计划；计划确认属于 HITL；确认后按步骤调度执行，步骤状态在任务监控面板可见；未确认或拒绝时不进入执行。
- **结果**：任务步骤、工具执行与最终产物均可在会话内追溯；计划步骤状态同步到监控面板。
- **异常**：执行中可中止；步骤失败需标记失败原因并允许重新生成或编辑重发。

#### FR-MODE-04 模式切换与隔离

- **规则**：模式属于会话属性，不在同一会话内混用；不同模式的会话在侧边栏统一列出但保留各自的执行方式；新建会话的默认模式由用户所在入口决定。
- **异常**：恢复历史会话时按会话记录的执行方式恢复；计划执行能力不可用时不得降级执行。

### 4.3 消息与过程展示

#### FR-MSG-01 用户消息气泡

- **规则**：用户消息右对齐展示；超过 5 行默认折叠，可点击气泡或“展开/收起”按钮切换；悬停显示时间、编辑、复制。
- **结果**：编辑入口仅在会话空闲且消息已持久化时出现。
- **边界**：拖选文本或点击消息内链接不触发折叠切换；图片附件点击进入应用内大图预览。

#### FR-MSG-02 助手消息与操作栏

- **规则**：助手消息通栏展示，不带气泡底色；消息结束后显示操作栏：复制、赞、踩、分享、重新生成；有 token 用量时展示总量；有执行轨迹时提供轨迹入口（Web 形态为胶囊，桌面内联展示）。
- **状态**：默认悬停显隐；触屏设备常显；运行中不展示操作栏。

#### FR-MSG-03 过程容器

- **规则**：一轮执行的思考、叙述、工具动作收进“过程容器”；运行中显示“运行中 · 已用 X”，终态显示“已完成 · 耗时 X”；终态自动收起，用户手动展开后保持当前选择。
- **内容**：深度思考以左竖线引用块展示，可展开查看完整思维链；工具行动作行展示中文动作名与参数摘要，可展开参数与观测结果；连续同类工具调用聚合为批次行。
- **异常**：空思考段不渲染；运行中的空内容以“准备中 / 开始思考”占位；工具执行失败标记为失败并可查看原因。

### 4.4 消息操作

#### FR-ACT-01 编辑重发

- **触发**：用户消息悬停操作栏的“编辑”；仅云端会话、会话空闲（非流式、非暂停）且消息已持久化时可用。
- **规则**：行内编辑卡片替换原气泡，支持自动增高、Enter 发送、Shift+Enter 换行、Esc 取消，输入法合成中的 Enter 不发送；提交后以该消息为新起点，更新正文并截断其后的全部消息与回复，重新执行本轮。
- **结果**：目标消息保持原位并显示新正文；后续消息被移除；新的助手回复重新流式产出；会话标题不变。
- **异常**：无法将该消息对齐到服务端真实记录时，不执行截断并提示“刷新后重试”；本地（离线）会话暂不开放编辑。

#### FR-ACT-02 重新生成

- **触发**：助手消息操作栏“重新生成”。
- **规则**：定位触发该回复的上一条用户消息，截断其后的消息并重新执行；沿用原回复所使用的模型，避免默认模型导致结果不可复现。
- **异常**：运行中禁止操作；找不到对应用户消息时提示，不做无依据的重跑。

#### FR-ACT-03 反馈、分享与停止

- **规则**：点赞/点踩为可取消状态，变更失败时回滚并提示；分享优先调用系统分享，不可用时复制正文；停止生成立即终止本次执行，已产出内容保留并进入终态。
- **结果**：反馈即时更新本端状态并异步同步；停止后仍可重新生成或继续提问；停止也会结算已消耗的用量。

### 4.5 HITL（人工在环）

#### FR-HITL-01 暂停与确认

- **触发**：Agent 在执行中需要用户确认工具调用、做出选择、确认计划或回答澄清问题时。

| 类型 | 用户看到的动作 | 用户可选 |
|---|---|---|
| 工具审批 | “等待你确认该操作”，展示工具与参数 | 批准 / 拒绝 / 修改参数 |
| 选择 | “等待你选择”，展示候选项 | 选择一个或多个选项 / 其他 |
| 方案确认 | “等待你确认方案”，展示计划 | 批准执行 / 拒绝 / 修改 |
| 澄清 | “正在询问用户”，展示问题 | 文本回答 / 跳过 |

- **规则**：暂停期间输入区切换为 HITL 精简态，禁止发起新一轮执行；恢复后继续写入同一条助手消息；审批默认有效期 300 秒，超时自动拒绝并进入可恢复终态。
- **异常**：恢复失败或暂停项已失效时明确提示，不留下悬空弹窗；用户点击停止等价于取消该待确认操作。

### 4.6 工具、技能与场景包

#### FR-AGENT-01 内置工具

- **规则**：Agent 可按需调用：时间获取、联网搜索、计算、文档写作；桌面本地运行时还可注册代码执行等敏感工具；工具调用需遵循敏感工具审批策略。
- **结果**：工具输入与输出进入执行轨迹；搜索结果以来源卡片展示；文档写作产物进入产物面板。

#### FR-AGENT-02 技能（Skills）

- **规则**：技能按能力分层；用户可在发送前选择本轮启用的技能（空数组表示明确不用）；管理员可控制平台技能的启用白名单，白名单持久化并在重启后生效。
- **结果**：技能决定本轮可用的工具集合；技能选择随用户消息保存，暂停恢复时沿用同一选择，避免工具集漂移。
- **权限**：普通用户只能选择已启用技能；管理操作对非管理员一律拒绝。

#### FR-AGENT-03 场景包与领域角色

- **规则**：产品内置研究写作与任务规划两个场景包；仅在启用时把领域角色接入提示词组装；分析模式默认研究写作领域，任务模式默认任务规划领域。
- **边界**：场景包未激活时不注入领域，不改变默认行为；场景包加载失败不阻断服务。

### 4.7 产物与来源

#### FR-ART-01 产物生成与预览

- **触发**：Agent 判断任务需要交付文档时，使用文档写作工具生成 Markdown 等文件。
- **规则**：产物自动命名并写入用户文档目录；生成后校验并登记为可追溯产物；消息内给出产物入口。
- **结果**：产物面板支持预览、复制正文、下载、关闭、跳回来源消息；删除会话不应误删已有文件。
- **异常**：写入失败需回传明确错误，不把失败当成功；空内容产物不得登记。

#### FR-ART-02 来源与引用

- **规则**：回答中的参考来源汇总到来源面板；来源项可点击打开；执行轨迹中的搜索观测可展开原始结果。
- **边界**：来源仅在真实检索产生时展示，不伪造引用；无来源时面板不出现。

### 4.8 文件与附件

#### FR-FILE-01 上传与附件展示

- **规则**：支持图片、PDF、纯文本；单文件上限 10MB；图片可多张随消息发送；附件在消息内以缩略图或文件卡片展示；图片支持应用内放大。
- **边界**：非图片类型的附件不得作为可执行内容在新窗口直接渲染；草稿图片存本地资产，不随草稿以明文大对象反复读写。

### 4.9 模型、密钥与用量

#### FR-MODEL-01 模型选择

- **规则**：对外暴露两个模型意图：标准对话（别名 fast）与深度推理（别名 reasoning）；用户可按会话选择模型或交由后端决定。
- **边界**：历史客户端可能仍发送展示名或旧 ID，服务端需将其收敛到当前真实模型；未知模型不允许静默替换，应给出可读错误。

#### FR-MODEL-02 自有模型与密钥（桌面）

- **规则**：桌面设置可维护模型列表（名称、提供方、模型 ID、启用状态）；密钥经系统密钥库加密存储，界面只回显掩码；可设置默认模型。
- **结果**：启用的模型出现在输入框模型选择器；默认模型决定新请求使用的模型；“Auto” 表示由后端决定。
- **安全**：明文密钥不得写入普通配置或日志；删除模型时同步清除对应密钥。

#### FR-MODEL-03 用量与配额

- **规则**：按用户设置每日 token 配额，0 表示不限；配额按自然日重置；请求前校验，超限返回明确的限流提示；一轮执行在终态（完成 / 暂停 / 错误 / 中止）都必须结算真实消耗。
- **展示**：会话与设置中展示 token 用量；成本面板按模型单价估算近 7 天调用。
- **异常**：未真正开始执行（例如初始化失败）不按估算值计费；部分完成被中止不得免费。

### 4.10 会话管理

#### FR-SESS-01 列表、分页与归档

- **规则**：会话按最近更新时间倒序；使用游标分页避免重复/跳过；可重命名、归档、恢复与删除；归档会话集中在设置的数据管理分区处理。
- **结果**：删除为不可逆操作，需二次确认；删除会话同时清理消息与关联执行记录。
- **边界**：加载历史失败不清空本地已有消息；切换会话时取消旧请求，避免串线。

#### FR-SESS-02 搜索与空间（现状）

- **现状**：桌面侧边栏提供“任务 / 空间”分组，空间为空态“即将开放”。`[占位]`
- **待定**：是否需要全局会话搜索、空间归属与跨设备同步，见开放问题。

### 4.11 插件·技能市场

#### FR-PLUGIN-01 Web 插件页

- **规则**：聚合两类对象：已接入的 MCP 服务与可安装目录；提供分类、搜索、推荐位、已安装状态与“添加插件”入口；安装需选择传输方式并填写连接信息。
- **状态**：已安装项展示连接状态；不支持安装的条目置灰；演示数据需标识，避免与真实服务混淆。

#### FR-PLUGIN-02 桌面插件页

- **现状**：提供插件 / 技能 / 工作伙伴三个页签、分类与卡片网格，但安装与管理状态仅保存在页面本地，未接通真实安装。`[占位]`

## 5. 共享规则与状态

### 5.1 角色与权限矩阵

| 能力 | 访客 | 普通用户 | 本地单用户 | 管理员 |
|---|---|---|---|---|
| 浏览官网 / 静态演示 | ✓ | ✓ | — | ✓ |
| 创建 / 读写自己的会话 | ✗ | ✓ | 仅本地 | ✓（自己的） |
| 选择已启用技能 | ✗ | ✓ | ✓（本地配置） | ✓ |
| 修改平台技能白名单 | ✗ | ✗ | ✗ | ✓ |
| 查看全量用户 / 成本指标 | ✗ | ✗ | ✗ | ✓ |
| 查看他人会话 | ✗ | ✗ | ✗ | ✗（不做越权） |

原则：用户数据按归属隔离；管理员权限不自动等于可读用户对话内容；本地模式不产生云端身份。

### 5.2 生命周期状态

| 对象 | 状态流转 | 禁止 / 回收 |
|---|---|---|
| 助手消息 | 待发送 → 流式 →（可选）暂停 → 恢复流式 → 完成 / 错误 / 已中止 | 运行中不发操作栏；中止视为终态，保留已产出内容 |
| HITL 项 | 待答复 → 批准 / 拒绝 / 回答 → 恢复执行 | 超时（审批 300 秒）自动拒绝；同一时刻只承接一个展示项，其余排队 |
| 会话 | 新建 → 活跃 → 归档 → 恢复 / 删除 | 删除不可逆；归档不删除消息；临时会话不可编辑重发 |
| 产物 | 生成 → 登记 → 预览 / 下载 | 空内容不登记；删除会话不删除已生成文件 |
| 技能 | 启用 ↔ 禁用 | 禁用后不再进入本轮工具集；管理员变更持久化 |

### 5.3 消息截断与重跑规则

- “编辑重发”与“重新生成”都以某条用户消息为锚点，截断该消息之后的全部消息与回复再重跑；前者更新正文，后者沿用原文。
- 被截断的消息在会话历史中不再出现；对应执行记录与计划步骤一并失效。
- 锚点必须能对上服务端真实消息；对不上时拒绝执行并提示刷新，不允许按位置猜测。
- 云端会话支持；本地会话的上下文由本地运行时维护，暂不支持编辑重发。

### 5.4 用量、配额与计费

- 配额按用户、按自然日；超限时阻止新一轮执行并返回明确文案。
- 已触达模型的执行在所有终态结算；未真正开始执行（例如初始化失败）不计费。
- 请求前可预占配额，结束后按真实用量结算，差额回补；并发请求不得绕过上限。
- 成本展示为估算值，单价来自模型目录；调价只影响后续统计。

### 5.5 错误、重试与超时

- 流式响应只设“空闲超时”（默认 60 秒无数据即中止），不设总时长上限；超时可重试。
- 网络或服务端错误发生在执行开始后，客户端可用事件游标续读，最多两次，不重复请求模型。
- 鉴权失败与限流有独立文案；鉴权失败清理登录态，限流提示稍后重试。
- 无最终回答的完成态必须展示兜底提示（可能达到工具上限或被中止），不能渲染为空白。

### 5.6 安全与数据

- Markdown 输出按白名单净化；链接拦截 `javascript:` 等危险协议；产物预览在沙箱环境中渲染。
- 上传按允许类型与大小校验；非图片附件不得以可执行页面形式打开。
- 模型密钥在桌面端经系统密钥库加密，界面与日志不回传明文。
- 桌面渲染进程启用沙箱与上下文隔离，内容安全策略限制外部脚本与连接来源。
- 会话删除、归档、编辑、重新生成等不可逆动作需可识别、可确认；删除需二次确认。
