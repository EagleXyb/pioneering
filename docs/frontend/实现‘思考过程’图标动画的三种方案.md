# 实现‘思考过程’图标动画的三种方案

要在 React 里实现「思考过程」图标动态效果，有两种主流、易实现的方案，我给你分别讲清楚，附带可直接用的代码示例。

---

## 方案一：纯 CSS 实现（推荐，性能最优）

用 CSS 动画实现图标旋转 / 呼吸 / 脉冲效果，不需要额外依赖，性能最好。

### 效果示例（以「旋转」为例）

1. 给图标加一个 CSS 类，实现无限旋转

2. 动画只在 “思考中” 状态开启，结束时移除

```tsx
import { Lightbulb } from 'lucide-react'; // 假设用灯泡图标

const ThinkingIcon = ({ isThinking }: { isThinking: boolean }) => {
  return (
    <Lightbulb
      className={`w-4 h-4 ${isThinking ? 'animate-spin' : ''}`}
    />
  );
};
```

配套 CSS（可以写在全局样式或 CSS Module 里）：

```css
/* 旋转动画 */
@keyframes spin {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}
.animate-spin {
  animation: spin 1s linear infinite;
}

/* 呼吸/脉冲动画（可选） */
@keyframes pulse {
  0%, 100% { opacity: 1; transform: scale(1); }
  50% { opacity: 0.6; transform: scale(1.1); }
}
.animate-pulse {
  animation: pulse 1.5s ease-in-out infinite;
}
```

### 进阶：组合效果（旋转 \+ 淡入淡出）

```css
@keyframes spinAndFade {
  0% { transform: rotate(0deg) scale(0.9); opacity: 0.7; }
  50% { transform: rotate(180deg) scale(1.1); opacity: 1; }
  100% { transform: rotate(360deg) scale(0.9); opacity: 0.7; }
}
.animate-thinking {
  animation: spinAndFade 1.5s ease-in-out infinite;
}
```

## 方案二：React \+ CSS\-in\-JS 实现（适合用 Tailwind 的项目）

如果你的项目用 Tailwind，可以直接用它的内置动画类，或者自定义 `@keyframes`。

### Tailwind 示例

1. 配置 `tailwind\.config\.js` 自定义动画：

```js
// tailwind.config.js
module.exports = {
  theme: {
    extend: {
      keyframes: {
        thinking: {
          '0%, 100%': { transform: 'rotate(0deg) scale(1)', opacity: 1 },
          '50%': { transform: 'rotate(180deg) scale(1.1)', opacity: 0.8 },
        }
      },
      animation: {
        thinking: 'thinking 1.5s ease-in-out infinite',
      }
    }
  }
}
```

2. 组件中直接使用：

```tsx
import { Lightbulb } from 'lucide-react';

const ThinkingHeader = ({ isThinking }: { isThinking: boolean }) => {
  return (
    <div className="flex items-center gap-2">
      <Lightbulb
        className={`w-4 h-4 ${isThinking ? 'animate-thinking' : ''}`}
      />
      <span>思考过程</span>
      <span className="text-xs text-gray-500">›</span>
    </div>
  );
};
```

## 方案三：使用 Framer Motion 实现更复杂的交互动画

如果想要更丝滑、可控的动画（比如随时间变化的摇摆、弹跳），可以用 `framer\-motion` 库。

### 1\. 安装依赖

```bash
npm install framer-motion
```

### 2\. 组件代码示例

```tsx
import { motion } from 'framer-motion';
import { Lightbulb } from 'lucide-react';

const ThinkingIcon = ({ isThinking }: { isThinking: boolean }) => {
  return (
    <motion.div
      animate={isThinking ? {
        rotate: [0, 180, 360],
        scale: [1, 1.1, 1],
        opacity: [1, 0.7, 1]
      } : {}}
      transition={{
        duration: 1.5,
        repeat: Infinity,
        ease: "easeInOut"
      }}
    >
      <Lightbulb className="w-4 h-4" />
    </motion.div>
  );
};
```

## 关键细节：动画的启停控制

要让动画只在 “思考中” 状态运行，需要和你的消息状态联动：

```tsx
// 假设你的消息有 status 字段
type Message = {
  id: string;
  role: 'user' | 'assistant';
  content: string;
  status: 'loading' | 'success' | 'error';
  thinking?: string; // 思考过程内容
};

const MessageBubble = ({ message }: { message: Message }) => {
  const isThinking = message.status === 'loading' && !!message.thinking;

  return (
    <div className="assistant-bubble">
      {message.thinking && (
        <div className="thinking-header">
          <ThinkingIcon isThinking={isThinking} />
          <span>思考过程</span>
        </div>
      )}
      {/* 渲染回答内容 */}
    </div>
  );
};
```

## 效果推荐（用户体验友好）

|效果类型|推荐场景|优点|
|---|---|---|
|脉冲 / 呼吸|不想太晃眼|柔和、不分散注意力|
|缓慢旋转|标准加载感|直观、符合用户对 “加载中” 的认知|
|轻微摇摆|活泼风格产品|有趣但不刺眼|
