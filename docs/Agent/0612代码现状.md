## 一、接口对照表

| 场景 | 普通模式 (normal) | 专业模式 (professional) |
|------|------------------|------------------------|
| **会话列表** | `GET /chat/sessions` | 复用 `GET /chat/sessions`（同一张表） |
| **创建会话** | `POST /chat/sessions` | `POST /agent/sessions` |
| **加载消息** | `GET /chat/sessions/{id}/messages` | `GET /agent/sessions/{id}/messages` |
| **发送消息** | `POST /chat/completions` | `POST /agent/completions` |
| **消息反馈** | `POST /chat/messages/{id}/feedback` | `POST /agent/messages/{id}/feedback` |
| **工具执行查询** | 无 | `GET /agent/messages/{id}/executions` |

## 二、普通模式 — 完整数据流

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 普通模式: 前端 handleSend → POST /chat/completions → 后端 LLM 大模型调用   │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  ① 前端 useAgentChat.handleSend()                                        │
│     │ chatMode === 'normal'                                              │
│     │                                                                    │
│     ├─► 无 session → createNewSession(title, model, 'normal')            │
│     │   └─► useSessionManager.createNewSession()                         │
│     │       └─► agentApi.createSession()                                 │
│     │           └─► POST /chat/sessions  {title, model}                  │
│     │               └─► 后端 chat.py: create_session()                   │
│     │                   └─► INSERT ChatSession (agent_mode=NULL)          │
│     │                                                                    │
│     ├─► createChatRequest({                                             │
│     │       sessionId, message, model, stream: true,                     │
│     │       deepThinking, webSearch, signal                               │
│     │   })                                                               │
│     │   └─► POST /chat/completions                                       │
│     │                                                                    │
│     │   ② 后端 chat.py: chat_completion()                                │
│     │      │                                                             │
│     │      ├─► 无 session → 创建 ChatSession                             │
│     │      ├─► INSERT user ChatMessage (role=user)                       │
│     │      ├─► session.message_count++                                   │
│     │      │                                                             │
│     │      ├─► stream_chat_completion()  ← agent_bridge.py               │
│     │      │   │                                                         │
│     │      │   ├─► _init_moduagent(): 注册 ModuAgent 组件                │
│     │      │   │   - BaseLLMReasoner (LLM 推理引擎)                       │
│     │      │   │   - TextPreprocessor (文本感知)                          │
│     │      │   │   - InMemoryShortTermMemory (短期记忆)                   │
│     │      │   │   - CalculatorTool + SearchTool (工具)                   │
│     │      │   │                                                         │
│     │      │   ├─► Coordinator.stream_request()                          │
│     │      │   │   └─► 异步迭代 coordinator 帧                           │
│     │      │   │                                                         │
│     │      │   └─► _coordinator_frame_to_frontend_event()                │
│     │      │       │  将 coordinator 帧转为 SSE 事件:                     │
│     │      │       │   - status → {type: "status", status: "..."}        │
│     │      │       │   - thinking → {type: "thinking_delta", content}    │
│     │      │       │                  → {type: "thinking_done"}           │
│     │      │       │   - token → {type: "answer_delta", content}         │
│     │      │       │   - done → {type: "answer_done"}                    │
│     │      │       │   - error → {type: "error", errorCode, message}     │
│     │      │       │                                                      │
│     │      │       └─► yield {"data": json.dumps(event)}                 │
│     │      │                                                             │
│     │      └─► 最后 yield __metadata__:                                  │
│     │          {"type":"__metadata__",                                    │
│     │           "payload":{thinkingContent, answerContent, toolCalls}}    │
│     │                                                                    │
│     │      └─► EventSourceResponse(event_generator())                    │
│     │          └─► SSE 流: data: {"type":"answer_delta","content":"你好"} │
│     │                      data: {"type":"__metadata__","payload":{...}} │
│     │                                                                    │
│     │   ③ SSE 流结束 → 后端持久化 assistant 消息                          │
│     │      └─► INSERT ChatMessage (role=assistant, content=full_content) │
│     │                                                                    │
│     ▼                                                                    │
│  ③ 前端 SSE 解析 (useAgentChat 内)                                        │
│     │                                                                     │
│     ├─► ReadableStream reader → line-by-line 解析                         │
│     │                                                                     │
│     ├─► 每行 data: {...} JSON.parse()                                     │
│     │   │                                                                 │
│     │   ├─► type === "__metadata__" → 跳过 (仅后端持久化用)               │
│     │   │                                                                 │
│     │   ├─► parsed.type 存在 → applyStreamEvent(parsed)                   │
│     │   │   └─► useStreamParser.applyStreamEvent()                        │
│     │   │       │                                                         │
│     │   │       ├─► 事件类型路由:                                          │
│     │   │       │   • status → 更新 currentPhase                          │
│     │   │       │   • thinking_delta → ThinkingStep 追加/累积            │
│     │   │       │   • thinking_done → ThinkingStep.status='success'      │
│     │   │       │   • tool_call_start → ToolCallStep 创建                 │
│     │   │       │   • tool_call_end → 标记完成                            │
│     │   │       │   • tool_result_end → ToolResultStep 创建               │
│     │   │       │   • answer_delta → TextStreamStep 追加/累积            │
│     │   │       │   • answer_done → TextStreamStep.status='success'      │
│     │   │       │   • error → ErrorStep 创建                              │
│     │   │       │                                                         │
│     │   │       └─► emitEventBusEvent() → agentEventBus 通知 UI          │
│     │   │                                                                 │
│     │   └─► parsed.content 存在 (无 type) → 降级为 answer_delta           │
│     │                                                                     │
│     └─► 流结束 → 标记 message.status='success', currentPhase='done'       │
│                                                                          │
│  ④ UI 渲染 (ChatMessageBubble)                                            │
│     │                                                                     │
│     ├─► 解析 steps 中的 TextStreamStep.content → markdown 渲染            │
│     ├─► chatMode !== 'professional' → 隐藏 ExecutionCard                  │
│     └─► 右侧 AgentStepsPanel 隐藏                                         │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

## 三、专业模式 — 完整数据流

```

│ 专业模式: 前端 handleSend → POST /agent/completions → 后端 Agent ReAct 执行│

│                                                                          │
│  ① 前端 useAgentChat.handleSend()                                        │
│     │ chatMode === 'professional'                                        │
│     │                                                                    │
│     ├─► 无 session → createNewSession(title, model, 'professional')      │
│     │   └─► useSessionManager.createNewSession()                         │
│     │       └─► agentApi.createAgentSession()                            │
│     │           └─► POST /agent/sessions                                 │
│     │               body: {title, model, agentMode: "react_agent"}       │
│     │               └─► 后端 agent.py: create_agent_session()            │
│     │                   └─► INSERT ChatSession (agent_mode="react_agent")│
│     │                                                                    │
│     ├─► createAgentRequest({                                            │
│     │       sessionId, message, stream: true, signal                      │
│     │   })                                                               │
│     │   └─► POST /agent/completions                                      │
│     │                                                                    │
│     │   ② 后端 agent.py: agent_completion()                              │
│     │      │                                                             │
│     │      ├─► 无 session → 创建 ChatSession (agent_mode="react_agent")  │
│     │      ├─► INSERT user ChatMessage (role=user)                       │
│     │      │                                                             │
│     │      ├─► stream_agent_completion()  ← agent_bridge.py              │
│     │      │   │                                                         │
│     │      │   ├─► _init_moduagent(): 注册 ModuAgent 组件                │
│     │      │   │                                                         │
│     │      │   ├─► Coordinator.stream_request()                          │
│     │      │   │   └─► 异步迭代 coordinator 帧                           │
│     │      │   │                                                         │
│     │      │   └─► 帧事件 → Agent SSE 事件转换:                           │
│     │      │       │                                                      │
│     │      │       │   thinking frame:                                    │
│     │      │       │     → _agent_sse("thinking",                         │
│     │      │       │         {type:"thinking", status:"success",         │
│     │      │       │          summary:"..."})                            │
│     │      │       │     → SSE: data:{"type":"thinking","summary":"..."} │
│     │      │       │                                                      │
│     │      │       │   tool_call_start frame:                             │
│     │      │       │     → _agent_sse("tool_call",                        │
│     │      │       │         {type:"tool_call", status:"running",        │
│     │      │       │          toolName:"...", executionId:"...",          │

│     │      │       │   tool_result frame:                                 │

│     │      │       │     → SSE: data:{"type":"tool_result","summary":...}│
│     │      │       │                                                      │
│     │      │       │   token frame:                                       │
│     │      │       │     → _agent_sse("text",                             │
│     │      │       │         {type:"text_stream", text:"你好"})           │
│     │      │       │     → SSE: data:{"type":"text_stream","text":"你好"}│
│     │      │       │                                                      │
│     │      │       │   done frame:                                        │
│     │      │       │     → _agent_sse("done", {})                         │
│     │      │       │     → SSE: data:{}                                   │
│     │      │       │                                                      │
│     │      │       │   error frame:                                       │

│     │      │       │                                                      │
│     │      │       └──► 最后 yield __agent_metadata__:                    │
│     │      │            {"type":"__agent_metadata__",                     │

│     │      │             "answerContent":"...",                           │
│     │      │             "promptTokens":0, "completionTokens":0,          │

│     │      │                                                             │
│     │      └─► EventSourceResponse(event_generator())                    │
│     │                                                                     │
│     │      └─► event_generator 中:                                        │
│     │          - 遇到 __agent_metadata__ → 提取 contentBlocks 等持久化    │
│     │          - 其他 SSE 事件 → 直接 yield 给前端                         │
│     │          - 流结束后 → INSERT assistant ChatMessage                  │
│     │                       + INSERT AgentToolExecution 记录              │
│     │                                                                    │
│     ▼                                                                    │
│  ③ 前端 SSE 解析 (useAgentChat 内)                                        │
│     │                                                                     │
│     ├─► ReadableStream reader → line-by-line 解析                         │
│     │                                                                     │
│     ├─► 每行 data: {...} JSON.parse()                                     │
│     │   │                                                                 │
│     │   ├─► type === "__agent_metadata__" → 跳过 (仅后端持久化)           │
│     │   │                                                                 │
│     │   └─► applyAgentEvent(parsed)  ← 内联解析器                         │
│     │       │                                                             │
│     │       ├─► switch (parsed.type):                                     │
│     │       │   • "thinking" → ThinkingStep 创建                          │
│     │       │   • "tool_call" → ToolCallStep 创建                         │
│     │       │   • "tool_result" → ToolResultStep 创建 + 更新 tool_call    │
│     │       │   • "text_stream" → TextStreamStep 追加/累积               │
│     │       │   • undefined + errorCode → ErrorStep 创建                  │
│     │       │   • undefined + 空对象 → done 标记所有 streaming 为 success │
│     │       │                                                             │
│     │       └─► 拼接 TextStreamStep.content → message.content            │
│     │                                                                     │
│     └─► agentEventBus.emit('run:finished')                                │
│                                                                          │
│  ④ UI 渲染 (三栏布局)                                                      │
│     │                                                                     │
│     ├─► 中间栏: ChatMessageBubble                                         │
│     │   ├─► chatMode === 'professional' → 显示 ExecutionCard              │
│     │   │   └─► 展示 Agent 执行状态卡片 (思考中/工具调用/完成)            │
│     │   └─► TextStreamStep.content → markdown 渲染                        │
│     │                                                                     │
│     └─► 右侧栏: AgentStepsPanel (仅 professional 模式)                    │
│         └─► 展示完整推理链:                                                │
│             ├─► ThinkingStepView ← 思考步骤                                │
│             ├─► ToolCallStepView ← 工具调用                                │
│             ├─► ToolResultStepView ← 工具结果                              │
│             ├─► TextStreamStepView ← 文本流                                │
│             └─► ErrorStepView ← 错误信息                                   │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

## 四、关键差异对比

| 维度 | 普通模式 | 专业模式 |
|------|---------|---------|
| **API 前缀** | `/chat/` | `/agent/` |
| **后端处理函数** | `stream_chat_completion()` | `stream_agent_completion()` |
| **SSE 事件类型** | `thinking_delta`/`answer_delta`/`status`/`__metadata__` | `thinking`/`tool_call`/`tool_result`/`text_stream`/`done`/`error`/`__agent_metadata__` |
| **前端解析器** | `useStreamParser.applyStreamEvent()` (事件总线 + step 构建) | 内联 `applyAgentEvent()` (轻量，直接 setMessages) |
| **SSE 解析模块** | `useStreamParser.ts` (200+ 行) | `useAgentChat.ts` 内联 (~100 行) |
| **事件总线** | 使用 `agentEventBus` (emit 各类事件) | 不使用 (`run:started`/`run:finished` 仅标记) |
| **UI 布局** | 左栏 + 中间栏 (两栏) | 左栏 + 中间栏 + 右栏 (三栏) |
| **ExecutionCard** | 隐藏 | 显示 |
| **AgentStepsPanel** | 隐藏 | 显示 |
| **Session 创建** | `POST /chat/sessions` | `POST /agent/sessions` (含 agentMode) |
| **消息加载** | `GET /chat/sessions/{id}/messages` → `MessageResponse` | `GET /agent/sessions/{id}/messages` → `AgentMessageResponse` (含 contentBlocks) |
| **数据库持久化** | ChatMessage (content + metadata) | ChatMessage (content + content_blocks) + AgentToolExecution |

## 五、`stream_chat_completion` vs `stream_agent_completion` 核心差异

两者都在 `agent_bridge.py` 中，都调用同一个 `Coordinator.stream_request()`，但事件转换层不同：

| 维度 | `stream_chat_completion` (普通模式) | `stream_agent_completion` (专业模式) |
|------|-----------------------------------|-----------------------------------|
| **事件转换函数** | `_coordinator_frame_to_frontend_event()` | 内联在 `stream_agent_completion` 中 |
| **thinking 事件** | `thinking_delta` + `thinking_done` | `thinking` (一次性 block) |
| **文本事件** | `answer_delta` (增量) | `text_stream` (增量) |
| **工具事件** | `tool_call_start`/`tool_call_end`/`tool_result_end` | `tool_call`/`tool_result` (一次性 block) |
| **完成事件** | `answer_done` | `done` (空对象 `{}`) |
| **metadata 格式** | `__metadata__` (payload 内嵌) | `__agent_metadata__` (contentBlocks 扁平) |
| **contentBlocks** | 不支持 | 构建完整 content_blocks 数组 |
| **tool_executions** | 不支持 | 提取工具执行明细 |
| **token 统计** | 不支持 | promptTokens + completionTokens |
| **延迟统计** | 不支持 | latencyMs |
