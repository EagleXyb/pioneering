## 关键决策

- **目标用户**：聚焦"想创业但不知道做什么"的人群（李然/王芳/陈浩三个画像）
- **产品命名**：创路 Agent（暂定）
- **三层价值**：功能价值（方向聚焦+快速验证）+ 情绪价值（创业搭子）+ 资产价值（创意库+知识图谱）
- **差异化定位**：Unlike 通用AI助手被动回答，我们主动引导+沉淀专属知识资产
- **技术架构**：五层架构，React+Next.js/Taro + FastAPI + 多模型网关 + PostgreSQL/MongoDB/Neo4j/Milvus

## 路线图概要

- Phase 0（W1-W4）：基础建设
- Phase 1（W5-W12）：MVP验证，100人内测
- Phase 2（W13-W24）：增长破局，1万用户，付费上线
- Phase 3（W25-W40）：规模成熟，10万用户

## 团队成员贡献

- 瑞思（用户研究）：3个画像、7条洞察、旅程图、情绪地图
- 竞析（竞品分析）：7大竞品、功能矩阵、SWOT、Battle Card
- 数析（数据分析）：TAM/SAM/SOM、定价策略、指标体系
- 析客（需求分析）：10章架构文档、7大核心模块、需求池
- 路径（路线图）：4阶段20Sprint详细计划、3个决策点

## 梁宁视角融入

- 点线面体：判断"AI赋能个体创业"是上升的"体"
- 真需求验证：方向聚焦+快速验证+情绪陪伴=Need，更多内容/工具=伪需求
- 情绪OS：恐惧是暗线，产品必须打破"兴奋→困难→搁置"的情绪死循环
- 价值-共识-模式：功能价值+情绪价值+资产价值三层闭环
