## 📌 TL;DR（执行摘要）

- **核心目标**：打造"创路 Agent"——一个帮助"想创业但不知道做什么"的人理清思路的AI Agent智能体
- **关键决策**：聚焦"想创业但不知道做什么"这个鲜明人群，提供三层价值（功能价值+情绪价值+资产价值），不做通用AI助手
- **差异化定位**：Unlike 通用AI助手只能被动回答创业问题，我们主动引导从"不知道做什么"到"清晰创业方案"，并沉淀专属创意知识资产——越用越懂你
- **下一步**：Phase 0 基础建设4周 → Phase 1 MVP 8周（100人内测）→ ★D1关键决策点

## 1. 梁宁视角：点线面体分析

### 体：AI赋能个体创业——正在加速上升

**三重驱动**：政策（灵活就业保障/创业支持）+ 技术（AI Agent成熟/一人公司成本降低92%）+ 社会（职业重构/个人品牌崛起）。类似于2010-2015年移动互联网的上升期。

### 面：创业方向选择服务——明确空白

在"有了想法后的执行工具"（Strategyzer/IdeaBuddy）和"通用问答"（Kimi/豆包）之间，缺少专门帮助"从0到1激发创意、理清思路"的AI Agent产品。

### 线：三层价值飞轮——聚焦→自信→沉淀→更聚焦

- **功能价值**：帮用户从"想法多"到"一个方向"（方向聚焦+快速验证）
- **情绪价值**：打破"兴奋→困难→搁置"的死循环（创业搭子，不是导师）
- **资产价值**：创意库+思维模型库+知识图谱（越用越懂你，用久了走不掉）

### 点：MVP核心——7个P0需求，25人周

创业领域专精对话引擎 → 方向聚焦引导 → 快速验证计划 → 用户画像与记忆 → 情绪识别 → 创意库 → 核心流程设计

## 2. 目标用户画像

| 画像 | 特征 | 核心痛点 | 付费意愿 |
|------|------|---------|---------|
| **李然**（28岁，困在格子间的梦想家） | 互联网大厂运营，有模糊方向但分析瘫痪 | 信息过载+怕选错赛道 | 月付300-500元 |
| **王芳**（35岁，被裁后醒悟的转身者） | 传统行业被裁，完全不知道能做什么 | 能力迁移迷茫+试错空间极小 | 一次性1000-3000元 |
| **陈浩**（23岁，满腔热血的毕业生） | 985工科硕士，想法太多无法聚焦 | 缺乏商业验证+无人可讨论 | 月付100-200元 |

**核心洞察**：70%以上用户卡在"迷茫→焦虑→停滞"的死循环。他们的真需求不是"给我一个点子"，而是"帮我判断我该做什么"。

## 3. 差异化竞争策略

### 市场空白

| 竞品类型 | 代表 | 短板 |
|---------|------|------|
| 通用AI助手 | Kimi/豆包 | 无创业领域专精，无个性化记忆，被动问答 |
| 商业计划工具 | Strategyzer/IdeaBuddy | 只帮"已有想法"的人，方法论与AI割裂 |
| 创业社区平台 | Indie Hackers/创业邦 | 无1对1引导，情绪支持非结构化 |
| 创新培训 | 混沌学园 | 重培训轻实践，方法论与AI脱节 |

### 核心壁垒（随时间增长）

1. **个性化记忆系统**：越用越懂用户，通用AI无法复制
2. **知识资产沉淀**：创意库+知识图谱=迁移成本
3. **情绪陪伴能力**：刻意设计的1对1"创业搭子"体验

## 4. 产品架构概要

```
┌──────────────────────────────────────────────┐
│             交互层 (Web/小程序)                │
│    对话界面 │ 方向看板 │ 创意库 │ 知识图谱     │
├──────────────────────────────────────────────┤
│             体验层                            │
│    情绪引擎 │ 主动引导 │ 个性化语气            │
├──────────────────────────────────────────────┤
│             能力层                            │
│  对话引擎 │ 方向聚焦 │ 方法论 │ 验证 │ 资产   │
├──────────────────────────────────────────────┤
│             智能层                            │
│  个性化记忆 │ 意图识别 │ 情绪识别 │ 知识推理   │
├──────────────────────────────────────────────┤
│             数据层                            │
│  PostgreSQL │ MongoDB │ Neo4j │ Milvus │ Redis │
└──────────────────────────────────────────────┘
```

### 七大核心模块

1. **智能对话引擎**：创业领域专精，Socratic引导式对话
2. **主动引导系统**：停滞3天提醒/验证受阻介入/方向偏移预警
3. **个性化记忆系统**：三层记忆架构（短期/中期/长期）
4. **创新方法论引擎**：设计思维→点线面体→精益创业→商业模式画布
5. **知识资产系统**：创意库+思维模型库+知识图谱
6. **情绪识别与陪伴系统**：打破"兴奋→困难→搁置"死循环
7. **方向聚焦与验证系统**：三维矩阵收敛+7天快速验证

## 5. 产品规划路线图概要

| 阶段 | 时间 | 主题 | 关键交付 | 成功指标 |
|------|------|------|---------|---------|
| Phase 0 | W1-W4 | 基础建设 | LLM Gateway+Prompt管理+核心数据模型 | 基础对话可用 |
| Phase 1 | W5-W12 | MVP验证 | P0全部7项+核心流程跑通+100人内测 | M3留存>35%，日均对话>5轮 |
| Phase 2 | W13-W24 | 增长破局 | P1全部7项+主动引导+付费体系+1万用户 | DAU/MAU>20%，付费转化>5% |
| Phase 3 | W25-W40 | 规模成熟 | P2选择性落地+10万用户 | M3留存>50%，付费转化>8% |

### 三个关键决策点

- **★D1（W12）**：MVP内测数据评估 → Go/Pivot/Stop
- **★D2（W24）**：付费验证评估 → 扩大投入/调整定价/重新思考商业模式
- **★D3（W36）**：规模化评估 → 继续扩展/聚焦优化/有序收缩

## ⚠️ 待确认 / 假设 / Non-goals

### 待确认
- 产品命名最终确定（"创路"或其他）
- MVP平台优先级（小程序先行 vs Web先行）
- 入门版定价（¥49 vs ¥68）
- 免费版对话次数（3次/天 vs 5次/天）

### 核心假设
- "想创业但不知道做什么"的人群愿意为"方向聚焦"付费
- AI Agent的引导式对话效果优于被动问答
- 个性化记忆+知识资产沉淀能形成足够切换成本

### Non-goals（明确不做）
1. 不做创业全流程工具（注册公司/财务/法务）
2. 不做创业内容平台（课程/文章/资讯）
3. 不做投融资对接
4. 不做通用AI助手
5. 不做"已有明确方向"的用户
6. 不做社交平台
7. 不做创业导师/咨询
8. 不做MVP之后的App原生开发
