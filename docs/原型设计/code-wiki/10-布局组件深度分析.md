# 布局组件深度分析

## 1. 概述

OpenCowork 的布局系统采用**弹性面板组合**架构，由 `Layout.tsx` 作为顶层容器，组合 5 大核心区域：

- **标题栏**（TitleBar）— 顶部导航与模式切换
- **导航栏**（NavRail）— 左侧垂直图标导航
- **工作区侧边栏**（WorkspaceSidebar）— 会话/项目树
- **主内容区**（SessionConversationPane / 各页面）— 核心工作区域
- **右侧面板**（RightPanel）— 上下文/工件/文件/计划等辅助面板

---

## 2. Layout — 顶层布局容器

**文件：** `src/renderer/src/components/layout/Layout.tsx`

### 2.1 职责

Layout 是渲染进程的**主布局容器**，负责：

1. 组合所有面板组件，管理整体布局结构
2. 监听全局键盘快捷键（约 20+ 个）
3. 根据 UI 状态切换内容视图（聊天/设置/技能/同步等）
4. 自动折叠侧边栏以适应小屏
5. 更新窗口标题（显示 streaming/SubAgent/pending 状态）
6. 在 chat/session 视图间同步 UI mode

### 2.2 布局结构

```tsx
<div className="flex h-screen">
  <NavRail />                            {/* 左侧导航栏，固定 48px 宽 */}
  
  <AnimatePresence>
    {showEmbeddedSidebar && (
      <PanelTransition side="left">
        <WorkspaceSidebar />             {/* 会话/项目侧边栏，可拖拽调整宽度 */}
      </PanelTransition>
    )}
  </AnimatePresence>

  <div className="flex min-w-0 flex-1 flex-col">
    <TitleBar />                         {/* 标题栏 + 模式切换 */}
    
    <div className="flex flex-1 min-h-0">
      {/* 主内容区域 */}
      {settingsPageOpen ? <SettingsPage /> : <MainContent />}
      
      <AnimatePresence>
        {rightPanelOpen && (
          <PanelTransition side="right">
            <RightPanel />              {/* 右侧面板 */}
          </PanelTransition>
        )}
      </AnimatePresence>
    </div>
  </div>
</div>
```

### 2.3 视图路由

Layout 通过 `chatView` 状态决定主内容区渲染的页面：

| chatView 值 | 渲染内容 | 触发条件 |
|---|---|---|
| `'home'` | `<ChatHomePage />` | 无活跃 session，首页 |
| `'project'` | `<ProjectHomePage />` | 选中项目，未进入会话 |
| `'session'` | `<SessionConversationPane />` | 进入某个会话 |
| `'archive'` | `<ProjectArchivePage />` | 项目归档页 |
| `'git'` | `<GitPage />` | Git 操作页 |
| `'channels'` | 通道列表页 | 消息通道管理 |

### 2.4 自动侧边栏折叠

当视口变窄时，Layout 会智能地自动折叠左侧侧边栏以保持主内容区的可读性：

```typescript
const MIN_MAIN_WORKSPACE_WIDTH_WITH_SIDEBAR = 720
const MULTI_RIGHT_PANEL_COLLAPSE_VIEWPORT = 1600

// 判断逻辑：当右侧面板打开且主工作区宽度不足 720px 时
// 或者当右侧面板数量 >= 2 且视口 < 1600px 时
const shouldCollapseSidebar =
  chatView === 'session' &&
  leftSidebarOpen &&
  (rightSidePanelsNeedSpace || mainWorkspaceTooNarrow)
```

## 4. WorkspaceSidebar — 工作区侧边栏

**文件：** `src/renderer/src/components/layout/WorkspaceSidebar.tsx`

### 4.1 职责

显示会话/项目的树形结构，是**会话管理**的核心面板。包含：

- 项目列表（含 pinned 项目）
- 会话列表（按项目分组，含 pinned 会话）
- 搜索、创建、删除、重命名、导出等操作
- 拖拽调整宽度

### 4.2 性能优化

**关键优化：浅比较避免无用渲染**

```typescript
function areSessionListsEqualForSidebar(a: Session[], b: Session[]): boolean {
  if (a === b) return true
  if (a.length !== b.length) return false
  for (let i = 0; i < a.length; i++) {
    const x = a[i], y = b[i]
    // 只比较侧边栏显示的字段，忽略消息内容变化
    if (x.id !== y.id || x.title !== y.title || x.mode !== y.mode ||
        x.createdAt !== y.createdAt || x.updatedAt !== y.updatedAt ||
        !!x.pinned !== !!y.pinned || x.messageCount !== y.messageCount ||
        x.pluginId !== y.pluginId || x.projectId !== y.projectId) {
      return false
    }
  }
  return true
}
```

WorkspaceSidebar 和 AppSidebar 都使用了这种自定义浅比较，确保消息流式更新时（消息内容频繁变化）侧边栏不会重新渲染。

### 4.3 流式会话标记

通过 `streamingSessionIdsSig`（用 `\u0000` 连接的所有 streaming session ID 字符串）的变化来标记正在流式输出的会话，显示加载动画。

### 4.4 右键菜单

支持丰富的右键操作：

- 会话：重命名、复制、导出 Markdown、导出 JSON、置顶、清除消息、删除、在独立窗口打开
- 项目：重命名、更新目录、切换模式、归档、置顶、删除
- 子菜单：Mode 切换（chat/clarify/cowork/code/acp）

## 7. SessionConversationPane — 会话对话面板

**文件：** `src/renderer/src/components/layout/SessionConversationPane.tsx`

### 7.1 职责

这是**聊天界面的核心容器**，负责组合消息列表、输入区域和运行时状态面板。

### 7.2 组件组合

```
SessionConversationPane
├── RuntimeStatusPanel          (可选，dock 模式或浮动模式)
├── MessageList                 (消息列表，可滚动)
│   ├── MessageItem[]
│   │   ├── UserMessage         (用户消息)
│   │   └── AssistantMessage    (助手消息)
│   └── StreamingMessage        (流式消息占位)
├── InputArea                   (输入区域，底部固定)
└── ProjectTerminalDock         (项目终端坞，底部弹出)
```

### 7.3 RuntimeStatusPanel 的 Dock/浮动模式

```typescript
const RUNTIME_STATUS_DOCK_MIN_PANE_WIDTH = 960

// 当剩余对话区域宽度 >= 960px 时 dock 到右侧
// 否则在消息列表内浮动显示
```

### 7.4 会话操作

提供丰富的会话级操作：

- **发送消息**：通过 `useChatActions().sendMessage()` 触发 Agent 循环
- **停止流式输出**：通过 `abortSession()` 中断
- **清空对话**：`clearSessionMessages()`
- **导出对话**：Markdown 格式导出 / 图片格式导出
- **在独立窗口打开**：通过 `openDetachedSessionWindow()` 打开新窗口
- **重命名**：内联编辑会话标题
- **全宽模式**：切换对话面板是否占满宽度

### 7.5 终端坞

当会话关联了项目时，支持底部弹出 `ProjectTerminalDock`，使用 `motion` 动画展开/收起：

```typescript
const TERMINAL_DOCK_TRANSITION = {
  duration: 0.24,
  ease: [0.22, 1, 0.36, 1]
}
```

## 10. 布局性能优化策略

1. **Zustand 浅比较**：WorkspaceSidebar 和 AppSidebar 使用自定义 `areSessionListsEqual` 函数，避免因消息内容变化导致侧边栏重渲染
2. **`\u0000` 分隔的信号量**：使用 `streamingSessionIdsSig` 等信号量字符串的引用变化来触发更新，而非遍历对象
3. **`useShallow`**：广泛使用 Zustand 的 `useShallow` 进行浅比较选择
4. **`useCallback`/`useMemo`**：关键回调和派生状态使用 memoization
5. **`lazy` + `Suspense`**：SettingsPage、SkillsPage、SoulsPage 等大型页面使用懒加载
6. **`AnimatePresence` + `PanelTransition`**：面板切换使用动画过渡，提升用户体验
7. **自动侧边栏折叠**：根据视口宽度自动隐藏侧边栏，避免内容区过窄
