# 04 - 渲染进程 UI 层

## 入口 (`src/renderer/src/App.tsx`)

渲染进程的入口点，负责：

1. **初始化顺序**：
   - 注册所有 Viewer（文件预览器）
   - 初始化 Provider Store（模型提供商配置）
   - 初始化 App Plugin Store（应用插件）
   - 挂载 Renderer Tool Bridge（工具桥接）
   - 挂载 Agent Stream 接收器
   - 初始化 Extension Store 并注册所有工具
   - 初始化 Channel Event Listener（渠道事件监听）

2. **路由（4 种渲染模式）**：
   - `appView=ssh` — SSH 终端视图
   - `appView=session&sessionId=xxx` — 独立会话窗口
   - 新手引导未完成 — 新手引导页面
   - 默认 — 主布局（Layout）

3. **事件监听器**：
   - 会话变更事件（`CHAT_SESSION_UPDATED` / `CHAT_SESSION_DELETED`）
   - Cron 事件（`cron:fired` / `cron:run-progress` / `cron:run-finished`）
   - 更新事件（`update:available` / `update:downloaded`）
   - SSH 配置变更事件
   - 全局记忆文件更新事件
   - 全局未处理 Promise 拒绝事件
