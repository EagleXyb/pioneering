# 00 - 项目概述

## 什么是 OpenCowork

OpenCowork 是一个开源的桌面端多智能体 AI 协作平台。它让 AI 助手直接运行在你的机器上，获得本地文件系统访问权限、Shell 执行能力，并集成丰富的工具生态，让 AI 真正参与到你的工作流中而不是仅仅停留在聊天窗口。

与传统的纯云端 AI 聊天界面不同，OpenCowork 将代理放在你的本地环境中：

- **直接文件系统访问** — AI 可以读取、编辑、搜索你的项目文件
- **Shell 命令执行** — 在本地或远程 SSH 服务器上运行命令、查看输出
- **完整上下文感知** — AI 可以自主探索代码库，不需要你手动复制粘贴
- **人工全程介入** — 透明的工具调用审批机制，每一步都在你的控制之下

**版本**: 1.0.8

## 核心特性

### 运行时

- **四层架构设计** — 主进程 / Preload 安全桥 / 渲染进程 UI / 提供商无关的 Agent 运行时
- **全栈 TypeScript** — 从 SQLite 到 IPC 再到 UI，全程类型安全
- **SSH 远程支持** — AI 通过 SSH 在远程主机上透明操作，集成 xterm.js 终端

### 五种会话模式

每种会话场景选择最合适的模式：

| 模式 | 用途 |
|------|------|
| `chat` | 普通问答，快速交流 |
| `clarify` | 提问澄清歧义，产出可评审的计划再动手 |
| `cowork` | 完整协作：代码搜索、文件 IO、Shell、浏览器、子代理委派 |
| `code` | 结对编程：聚焦代码生成和精准编辑，集成 Monaco Editor |
| `acp` | 架构控制：澄清→设计→分解→委派给子代理实现 |

### 工具系统

- **文件与 Shell** — 读取、写入、编辑、Glob 搜索、Grep 搜索、Bash 执行（本地+SSH）
- **浏览器** — 内置 Webview，支持导航、截图、点击、输入、内容提取
- **任务与团队** — 任务分解，并行子代理，Agent Team 编排
- **计划模式** — 先写计划再执行，结构化可评审
- **目标追踪** — 创建、追踪、完成会话级目标，支持 Token 预算
- **记忆系统** — 分层记忆：全局 `SOUL.md` / `USER.md` / `MEMORY.md` + 项目级 `.agents/` 覆盖
- **Cron 代理** — 定时后台任务，支持多渠道投递
- **MCP 客户端** — 连接 Model Context Protocol 服务器（stdio/SSE/streamable-http）
- **技能系统** — 从技能市场安装领域技能，动态加载
- **自定义扩展** — 声明式 HTTP 工具、沙箱 JS 处理器、自定义 HTML 渲染器

### 持久化

- **SQLite** — 消息、会话、项目、任务、计划在重启后保留

## 目标用户与使用场景

### 目标用户

- **开发者** — 需要 AI 辅助编程，但又不想把代码泄露给第三方
- **团队协作者** — 需要多智能体分工完成复杂任务
- **自动化爱好者** — 需要定时运行 AI 任务（日报汇总、监控分析）
- **研究人员** — 需要在本地环境处理敏感数据，同时利用大模型能力

### 典型使用场景

1. **新项目脚手架搭建** — AI 根据需求选择技术栈，生成基础代码结构
2. **遗留代码重构** — AI 阅读现有代码，提出重构方案并逐步实施
3. **代码评审** — 配置子代理团队，多轮评审提高代码质量
4. **文档写作** — 定时抓取会议记录，自动整理成工作日志
5. **远程服务器维护** — 通过 SSH 连接，AI 协助排查问题
6. **多渠道机器人** — 将 OpenCowork 能力接入企业即时通讯，提供自动问答
