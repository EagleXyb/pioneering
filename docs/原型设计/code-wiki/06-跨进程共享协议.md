# 06 - 跨进程共享协议

## 概述

`src/shared/` 目录包含跨所有进程（Main / Preload / Renderer）共享的 TypeScript 类型定义和工具函数。这些文件在主进程和渲染进程之间建立契约，确保类型安全。

## 文件清单

`src/shared/` 包含 15 个文件/目录：

| 文件 | 用途 |
|------|------|
| `agent-stream-protocol.ts` | Agent Stream 协议 — 约 40+ 事件类型 |
| `agent-loop-types.ts` | Agent 循环类型（TokenUsage 等） |
| `team-runtime-types.ts` | Team 运行时类型 |
| `sync-types.ts` | WebDAV 同步类型 |
| `migration-types.ts` | 数据迁移类型 |
| `memory-automation-types.ts` | 记忆自动化类型 |
| `extension-types.ts` | 扩展清单和工具定义类型 |
| `input-draft-types.ts` | 输入草稿类型 |
| `browser-plugin.ts` | 浏览器插件配置 |
| `builtin-souls.ts` | 内置人格定义 |
| `shell-output-compactor.ts` | Shell 输出压缩器 |
| `live-tool-input-summary.ts` | 实时工具输入摘要 |
| `openai-responses-session.ts` | OpenAI Responses 会话类型 |
| `messagepack/binary-ipc.ts` | MessagePack 二进制 IPC 频道定义 |
| `messagepack/agent-stream-codec.ts` | Agent Stream 编解码器 |

## Agent Stream 协议 (`agent-stream-protocol.ts`)

这是 OpenCowork 的"网络协议"— 定义 Agent 运行时与 UI 之间所有通信事件。

### 协议版本

```typescript
export const AGENT_STREAM_PROTOCOL_VERSION = 1
```

### 信封格式

```typescript
export interface AgentStreamEnvelope {
  v: 1                               // 协议版本
  runId: string                      // 运行 ID
  sessionId: string                  // 会话 ID
  seq: number                        // 序列号（用于排序和去重）
  events: AgentStreamEvent[]         // 事件列表（可能批量发送）
}
```

### 事件类型（40+ 种）

参见 05-Agent 运行时与工具系统.md 中的详细事件类型列表。

### 关键子类型

| 类型 | 说明 |
|------|------|
| `TokenUsageWire` | Token 用量统计（含缓存命中、推理 Token、请求耗时） |
| `ToolCallStateWire` | 工具调用运行时状态 |
| `ToolUseBlockWire` | 工具调用块（来自 LLM） |
| `ToolResultWire` | 工具执行结果 |
| `RequestDebugInfoWire` | 请求调试信息（URL、headers、body） |
| `MessageWire` | 最小化消息格式 |

## Team Runtime 类型 (`team-runtime-types.ts`)

定义 Team 运行时相关的所有类型：

- `CreateTeamRuntimeArgs` — 创建团队的参数
- `DeleteTeamRuntimeArgs` — 删除团队的参数
- `AppendTeamRuntimeMessageArgs` — 追加消息的参数
- `GetTeamRuntimeSnapshotArgs` — 获取快照的参数
- `UpdateTeamRuntimeManifestArgs` — 更新 Manifest 的参数
- `UpdateTeamRuntimeMemberArgs` — 更新成员的参数
- `ConsumeTeamRuntimeMessagesArgs` — 消费消息的参数
- `TeamRuntimeCreateResult` — 创建结果
- `TeamRuntimeMessageRecord` — 消息记录
- `TeamRuntimeSnapshot` — 快照类型

## Sync 类型 (`sync-types.ts`)

WebDAV 同步相关类型：

- `WebDAVConfig` — WebDAV 服务器配置
- `SyncOperation` — 同步操作（push/pull/twoway）
- `ConflictResolution` — 冲突解决策略
- `SyncResult` — 同步结果

## Migration 类型 (`migration-types.ts`)

数据迁移类型，用于从其他平台（如 Cursor/Claude Code/OpenCode）迁移数据。

## Memory Automation 类型 (`memory-automation-types.ts`)

记忆自动化规则类型：

- `MemoryAutomationRule` — 记忆自动化规则
- `MemoryPipelineConfig` — 记忆处理管道配置
- `MemoryTrigger` — 触发条件

## Extension 类型 (`extension-types.ts`)

扩展系统的类型定义：

| 类型 | 说明 |
|------|------|
| `ExtensionToolKind` | 工具种类：`http` / `js` |
| `ExtensionUiKind` | UI 种类：`card` / `table` / `form` / `chart` / `html` / `component` |
| `ExtensionConfigFieldSchema` | 配置字段模式 |
| `ExtensionHttpDefinition` | HTTP 工具定义 |
| `ExtensionToolDefinition` | 工具定义（名称、描述、输入模式） |
| `ExtensionManifest` | 扩展清单（SchemaVersion、ID、名称、权限、工具列表等） |
| `ExtensionInstance` | 扩展实例（启用状态、安装时间） |

## Browser Plugin 类型 (`browser-plugin.ts`)

浏览器插件配置：

- `BrowserPluginConfig` — 浏览器插件配置
- 浏览器会话管理类型

## Shell Output Compactor (`shell-output-compactor.ts`)

Shell 输出压缩器，用于压缩长输出以减少 Token 消耗：

- 自动检测可压缩输出
- 保留头部和尾部
- 压缩中间部分
