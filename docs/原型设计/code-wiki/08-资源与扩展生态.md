# 08 - 资源与扩展生态

## 概述

OpenCowork 的资源生态由 `resources/` 目录管理，包含技能（Skills）、人格（Souls）、预定义 Agent（Agents）、扩展（Extensions）和自定义命令（Commands）五个子系统。它们共同构成了一个可扩展的 AI 协作平台。

## 资源目录结构

```
resources/
├── skills/          # 领域技能（11 个）
├── souls/           # 人格设定（6 个）
├── agents/          # 预定义 Agent（18 个）
├── extensions/      # 自定义扩展
└── commands/        # 自定义命令
```

## Skills 技能系统 (`resources/skills/`)

技能是为 AI 提供的领域知识包，每种技能有独立的 SKILL.md 文档和可选脚本。

### 11 个内置技能

| 技能 | 目录 | 用途 |
|------|------|------|
| PDF | `pdf/` | PDF 文件读写和处理 |
| DOCX | `docx/` | Word 文档读写和处理 |
| XLSX | `xlsx/` | Excel 电子表格读写 |
| CSV Pipeline | `csv-pipeline/` | CSV 数据处理流水线 |
| Web Scraper | `web-scraper/` | 网页内容抓取 |
| Image OCR | `image-ocr/` | 图片文字识别 |
| Email Drafter | `email-drafter/` | 邮件草稿生成 |
| Frontend Skill | `frontend-skill/` | 前端开发辅助 |
| Product Design | `product-design/` | 产品设计辅助 |
| Post to X | `post-to-x/` | 发布到 X（Twitter） |
| Create Extension | `create-extension/` | 创建自定义扩展 |

### 技能文件结构

每个技能目录包含：

```
skill-name/
├── SKILL.md          # 技能描述和指令（必需）
└── scripts/          # 可选辅助脚本
    ├── script1.ts
    └── ...
```

### 技能加载机制

1. 渲染进程通过 IPC 调用 `skills-handlers.ts` 获取技能列表
2. 用户选择技能后，SKILL.md 内容注入到系统提示词中
3. 技能可选脚本通过 `skills-store.ts` 管理加载
4. Agent 运行时根据技能提示词调整行为

## Souls 人格系统 (`resources/souls/`)

Soul（人格）定义了 AI 助手的角色定位和交互风格。

### 6 个内置人格

| 人格 | 文件 | 角色定位 |
|------|------|---------|
| 平衡型协作者 | `balanced-collaborator.json` | 默认，中立平衡 |
| 高级工程伙伴 | `senior-engineering-partner.json` | 资深工程师风格 |
| 日常生活助手 | `daily-life-assistant.json` | 生活化、友好 |
| 情感陪伴 | `emotionally-attuned-companion.json` | 共情、温暖 |
| 研究写作策略师 | `research-writing-strategist.json` | 学术、严谨 |
| 产品策略运作者 | `product-strategy-operator.json` | 商业、战略 |

### 人格文件格式

```json
{
  "name": "人格名称",
  "description": "简短描述",
  "system_prompt": "扩展系统提示词内容",
  "traits": ["list", "of", "traits"],
  "style": "communication style"
}
```

### 人格加载机制

1. 用户通过设置面板选择人格
2. 选择后写入 `~/.open-cowork/memory/SOUL.md`
3. Agent 启动时加载 SOUL.md 注入系统提示词
4. 人格可以被项目级 `.agents/SOUL.md` 覆盖

## Extensions 扩展系统 (`resources/extensions/`)

扩展系统允许第三方开发者扩展现有能力。

### 扩展清单格式 (`ExtensionManifest`)

```typescript
interface ExtensionManifest {
  schema_version: 1
  id: string                    // 唯一 ID
  name: string                  // 显示名称
  version: string               // 版本号
  description?: string
  tools: ExtensionToolDefinition[]   // 工具列表
  ui?: ExtensionUIDefinition[]       // UI 组件
  permissions?: string[]        // 所需权限
  config?: Record<string, ConfigFieldSchema>  // 配置字段
}
```

### 工具类型

| 类型 | 说明 | 执行环境 |
|------|------|---------|
| `http` | 声明式 HTTP API 调用 | 渲染进程 |
| `js` | 沙箱 JavaScript 处理器 | 隔离的 JS 运行时 |

### UI 类型

| 类型 | 说明 |
|------|------|
| `card` | 信息卡片 |
| `table` | 数据表格 |
| `form` | 表单 |
| `chart` | 图表 |
| `html` | 自定义 HTML 渲染器 |
| `component` | React 组件 |

### 示例：My Coffee 扩展

`resources/extensions/my-coffee/` 是一个瑞幸咖啡点单演示扩展：

```
my-coffee/
├── extension.json     # 扩展清单
├── tool-*.ts          # HTTP 工具定义
├── card-renderer.tsx  # 自定义 HTML 渲染器
└── ...
```

### 扩展生命周期

```
发现 → 安装 → 配置 → 启用 → 运行 → 禁用 → 卸载
  │       │        │       │      │       │       │
  IPC     IPC    扩展    App    Agent   App     IPC
  扫描    安装    设置   启用   运行时   禁用    卸载
                   面板   扩展   加载工具
```

### 相关 IPC 处理器

- `extension-handlers.ts` — 扩展增删改查
- `extension-native-bridge.ts` — 扩展原生桥接
- `extension-js-runtime.ts` — 扩展 JS 运行时

### 相关 Store

- `extension-store.ts` — 扩展状态管理

## Commands 自定义命令 (`resources/commands/`)

### 命令文件格式


## 技能市场与人格商店

Skills 和 Souls 的 UI 管理在：

- `src/renderer/src/components/skills/` — 技能管理组件
- `src/renderer/src/components/souls/` — 人格管理组件
- `src/renderer/src/components/settings/SkillsMarketPanel.tsx` — 技能市场面板
- `src/renderer/src/stores/skills-store.ts` — 技能 Store
- `src/renderer/src/stores/souls-store.ts` — 人格 Store

## 技术要点

1. **动态加载** — 技能和人格在运行时加载，无需重启应用
2. **提示词注入** — 技能提示词在 Agent 启动时注入系统提示词
3. **项目覆盖** — 项目级 `.agents/` 目录可以覆盖全局设置
4. **沙箱安全** — 扩展 JS 处理器在隔离环境中运行
5. **权限控制** — 扩展在 manifest 中声明所需权限，用户安装时审核
