# 三栏布局 整体设计架构思路、优势、浏览器端落地设计

## 一、核心架构设计思路

### 1. 底层架构思想

**分区职责分离 + 空间优先级分层 + 固定 + 弹性混合布局**

1. **功能垂直分区**
   全局横向切三栏，**每一栏只承载一类核心业务**，不交叉混杂：
   - 左栏：**导航 / 资源 / 会话列表**（数据入口、层级管理）
   - 中栏：**核心业务主画布**（用户主要操作、内容展示、交互输出）
   - 右栏：**附属工具 / 辅助面板**（调试、终端、参数、预览、日志）
2. **空间分配策略**
   - 左右两侧：**固定宽度**，保证布局稳定、视觉统一
   - 中间主体：**弹性自适应宽度**，独占剩余可视区域
3. **层级流布局**
   整体外层：水平横向 Flex
   每一栏内部：垂直纵向 Flex
   统一遵循 **顶部标题栏 + 中间滚动内容区 + 底部操作栏** 三段式内部结构
4. **滚动隔离原则**
   页面整体禁止滚动，**仅内容区域内部独立纵向滚动**，顶部导航、底部输入、侧边栏菜单全局固定不动。

## 二、该布局核心优势（业务 + 体验 + 开发）

### 1. 用户体验优势

1. **注意力聚焦**
   核心操作永远在中间大屏区，左右为辅，符合人眼居中视觉习惯
2. **多任务并行高效**
   一边选会话 / 分类、一边聊天编辑、一边调试查看日志，**三窗口并行互不遮挡**
3. 操作路径最短
   导航在左随手点，辅助工具在右随手开，无需弹窗跳转
4. 布局稳定不混乱
   窗口缩放、内容再多，结构不变，学习成本极低

### 2. 产品业务优势

1. **扩展性极强**
   左栏可无限加分类、会话、项目；右栏可随意新增工具面板、配置面板、预览面板
2. **业务边界清晰**
   管理层、业务层、工具层三层解耦，后期迭代互不影响

### 3. 开发架构优势

1. **结构标准化**
   全页面统一布局范式，组件复用率极高
2. **样式极易维护**
   栏与栏样式隔离，互不干扰
3. **状态独立管理**
   左侧列表状态、中间对话状态、右侧终端状态可分开维护
4. 适配简单：仅需控制栏宽，无需大规模重构

## 三、浏览器端标准落地设计规范（前端通用）

### 1. 全局基础约束

```css
html,body {
  height: 100vh;
  overflow: hidden; /* 禁止页面整体滚动 */
}
.app-wrap {
  display: flex;
  width: 100vw;
  height: 100vh;
}
```

### 2. 三栏宽度标准设计（浏览器端通用取值）

- 左侧导航栏：**200px \~ 240px**（主流 220px）
- 右侧工具面板：**280px \~ 360px**（终端 / 调试常用 320px）
- 中间主区：`flex: 1` 自动填满剩余宽度

### 3. 每一栏内部统一结构（强制统一范式）

**任意一栏内部都采用：上中下三段式**

```css
.col {
  display: flex;
  flex-direction: column;
  height: 100%;
}
.col-header {
  flex-shrink: 0; /* 固定高度不压缩 */
}
.col-main {
  flex: 1;
  overflow-y: auto; /* 唯一滚动区域 */
}
.col-footer {
  flex-shrink: 0; /* 底部固定 */
}
```

- 头部：标题、切换、功能按钮
- 中部：海量列表 / 内容 / 日志（唯一可滚动）
- 底部：用户信息、输入框、快捷操作

### 4. 浏览器端交互设计规则

1. **栏宽拖拽调节**
   左右栏与中间栏之间增加**可拖动分割线**，支持用户自主宽窄调整
2. **侧边栏折叠收起**
   小屏 / 全屏使用时，支持一键收起左栏、收起右栏，最大化中间工作区
3. **面板切换机制**
   右侧不局限单一终端，支持**多标签切换**：终端、参数、文档、预览、设置
4. **悬浮置顶规则**
   输入框、发送栏、顶部导航**永远置顶 / 置底**，滚动内容不会遮挡操作入口

### 5. 浏览器端兼容性设计

1. 优先使用 **Flex 布局**，兼容所有现代浏览器
2. 滚动区域统一用 `overflow\-y:auto`，避免自定义滚动条错乱
3. 禁止使用百分比高度嵌套混乱，全部依托 `100vh` 视口高度
4. 最小视口限制：低于 1200px 自动触发侧边栏默认收起，保证可用性

### 6. 适合浏览器端的业务场景

- AI 网页对话客户端
- 文档 + 编辑 + 预览三合一平台

## 四、总结一句话架构逻辑

**以「左右固定功能区、中间弹性主业务区」为空间骨架，以「外横内竖 Flex」为布局内核，以「固定头尾 + 中间独立滚动」为内部统一结构，实现浏览器端重交互、多面板、高效率的专业级桌面应用布局。**

## 五、三栏布局

#### 一、整体布局结构

该页面采用 **「侧边栏 + 主内容区（双栏）」** 的三栏响应式布局，结构如下：

| 区域    | 宽度占比  | 圆角             | 边框 / 间距               |
| ----- | ----- | -------------- | --------------------- |
| 左侧侧边栏 | 约 20% | 无              | 无内边框，与右侧主内容区无间隙       |
| 主内容左栏 | 约 60% | 8px（顶部 + 底部圆角） | 右侧与右栏之间有 1px/8px 分隔间距 |
| 主内容右栏 | 约 20% | 8px（顶部 + 底部圆角） | 无额外边框，整体容器与页面边缘有统一外间距 |

***

#### 二、样式细节规范

1. **全局容器**
   - 页面整体外间距：四周统一 `16px` 或 `24px`，保证内容不贴边
   - 布局高度：默认撑满视口高度（`min\-height: 100vh`），或由内容自适应撑开
   - 背景色：页面整体背景为 `\#f3f3f3`，与侧边栏背景色保持一致
2. **侧边栏（左栏）**
   - 宽度：固定 / 弹性宽度（如 `200px` 或 `20vw`），高度 100% 撑满父容器
   - 背景色：`\#f3f3f3`，无圆角、无内边距 / 外边距
   - 功能定位：导航 / 菜单区，可内部滚动，不影响主内容区
3. **主内容区（中间 + 右侧）**
   - 整体容器：`display: flex` 水平排列，中间与右侧栏为 flex 子项
   - 中间主栏：flex-grow 占比最大（约 3 倍于右侧栏），背景纯白，圆角仅作用于容器的左上角、左下角、右上角、右下角（即容器整体圆角，非分栏）
   - 右侧辅助栏：固定 / 弹性宽度（如 `200px` 或 `20vw`），背景纯白，圆角规则与中间栏一致
   - 栏间距：中间与右侧栏之间有 `8px` 间距，无分割线，仅留白分隔
   - 内边距：中间 / 右侧栏内部可预留 `16px` 内边距，用于放置业务内容
4. **响应式规则（补充可开发约束）**
   - 桌面端（≥1200px）：三栏布局保持原样，侧边栏固定宽度，主内容区自适应
   - 平板端（768px-1199px）：右侧辅助栏可隐藏，或调整为中间主栏下方堆叠布局
   - 移动端（\&lt;768px）：侧边栏转为顶部导航 / 抽屉菜单，主内容区改为单栏布局

***

#### 三、交互与扩展需求

- 侧边栏支持固定定位，滚动时不随页面移动
- 中间 / 右侧栏支持独立滚动，不影响整体布局
- 圆角、间距、背景色需支持全局变量配置，方便主题切换
- 布局支持嵌套业务组件，如卡片、列表、表单等，不影响整体结构
