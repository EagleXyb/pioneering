# 网页版AI对话产品通用设计规范

本规范基于豆包网页版布局样式提炼，适用于各类网页版AI对话产品，核心围绕“简洁高效、交互流畅、适配多元”的原则，明确整体布局、区域设计及交互逻辑，确保产品体验统一、易用，同时保留设计灵活性。

# 一、整体布局结构

网页版AI对话产品整体采用“分栏式布局\+固定功能区”结构，遵循响应式设计原则，适配桌面端、平板端等不同设备，核心区域划分清晰，优先级明确，兼顾操作效率与视觉舒适度。

## 1\.1 核心布局框架

整体分为四大核心区域，各区域功能独立、衔接流畅，具体分布如下：

- 左侧功能栏：固定于页面左侧，可折叠隐藏，核心承载对话管理、功能入口等，占比约20%；

- 右侧主内容区：页面核心区域，占比约80%，承载对话展示、内容编辑等核心交互；

- 顶部导航区：固定于页面顶部，不随滚动条移动，负责功能模块切换、用户中心等；

- 底部输入区：固定于页面底部，负责用户指令输入、功能调用，是用户与AI交互的核心入口。

## 1\.2 响应式适配原则

- 桌面端（≥1200px）：完整展示四大区域，左侧功能栏固定宽度，右侧主内容区自适应，充分利用大屏幕空间；

- 平板端（768px\-1199px）：左侧功能栏支持折叠，折叠后仅显示核心图标，主内容区自适应宽度；

- 移动端（≤767px）：左侧功能栏自动隐藏，通过顶部菜单触发显示，底部输入区优化为拇指操作尺寸，主内容区全屏展示。

# 二、各区域详细设计

## 2\.1 左侧功能栏（对话与功能管理区）

核心功能：对话管理、智能体/功能入口、个人设置，设计以“简洁、易检索”为核心，避免冗余信息。

### 2\.1\.1 顶部区域

- 品牌标识：左上角展示产品Logo，点击可返回首页，强化品牌认知；

- 折叠控制：Logo右侧设置折叠/展开图标，点击可隐藏/显示侧栏，最大化主内容区使用空间；

- 新建入口：显眼的“\+”按钮，一键创建新对话，支持快速选择对话类型（如普通对话、智能体对话）。

### 2\.1\.2 中间核心区

- 内容分组：按“对话历史”“智能体”“收藏”等维度分组，支持自定义标签分类，提升检索效率；

- 对话列表项：统一展示对话标题（自动提取核心内容或用户自定义）、最新消息预览（限制字数，避免换行）、最后互动时间戳，支持拖拽排序、右键操作（重命名、置顶、删除）；

- 功能入口：独立分组展示智能体、常用工具等，图标\+文字结合，清晰易识别，支持快速切换。

### 2\.1\.3 底部区域

- 个人中心：圆形用户头像，点击展开个人信息、账号设置等菜单；

- 系统设置：齿轮图标，进入主题、字体、快捷键等系统设置界面；

- 模式切换：月亮/太阳图标，支持浅色/深色模式快速切换，适配不同使用环境。

## 2\.2 右侧主内容区（核心交互区）

核心功能：展示对话内容、编辑生成内容，设计以“清晰、易阅读、多格式兼容”为核心，提升交互沉浸感。

### 2\.2\.1 顶部导航条

- 功能切换：设置“聊天”“写作”“图片”“文档”“代码”等核心功能标签，无刷新切换，标签状态清晰（当前功能高亮）；

- 对话管理：显示当前对话标题，支持点击编辑重命名；配备分享、收藏、删除、清空等快捷操作按钮，图标简洁统一；

- 辅助功能：可根据当前功能显示辅助入口（如文档导出、内容翻译），不占用核心视觉空间。

### 2\.2\.2 中间对话展示区

- 消息气泡设计：用户消息右侧对齐，AI消息左侧对齐，通过背景色、轻微阴影区分，圆角设计提升友好度；

- 内容兼容：支持文本、图片、表格、代码块、公式等多种格式，适配不同使用场景：


    - 代码块：暗色背景、语法高亮，配备复制按钮，提升代码查看与使用效率；

    - 表格：边框清晰、表头加粗，支持排序、导出功能；

    - 图片：自适应主内容区宽度，点击可放大查看，支持保存；

    - 公式：精准渲染，支持复制公式代码。

- 操作控件：每条AI回复下方配备“复制”“重新生成”“点赞/点踩”“展开/折叠”等按钮，图标小巧不突兀，hover时显示提示，提升操作便捷性。

### 2\.2\.3 右侧快捷工具区（可选）

当使用写作、文档处理等特定功能时，显示辅助工具面板，包含风格调整、长度控制、格式转换等功能，可折叠隐藏，不干扰核心对话展示。

## 2\.3 底部输入区（指令输入区）

核心功能：用户输入指令、调用功能，设计以“便捷、高效、容错”为核心，降低输入门槛。

- 主输入框：宽屏设计，高度自适应，支持多行输入；圆角边框，聚焦时高亮提示，内置实时字数统计，显示输入字符数；

- 功能按钮区（输入框左侧）：图标式设计，包含语音输入、图片上传、文档上传、更多工具等入口，图标统一为线性风格，hover时显示功能提示；文档上传支持常见格式，明确限制单个文件大小；

- 发送控制：右侧设置高亮发送按钮（图标或文字），支持快捷键操作（Enter发送、Shift\+Enter换行），“/”快捷键可快速召唤功能菜单，提升输入效率。

# 三、交互设计特点

交互设计以“高效、流畅、低学习成本”为核心，贴合用户使用习惯，减少操作步骤，提升用户体验，同时兼顾个性化需求。

## 3\.1 高效操作设计

- 快捷键支持：覆盖核心操作，如Enter发送、Shift\+Enter换行、“/”召唤功能菜单、Ctrl\+Up/Down切换历史消息，降低操作成本；

- 自动聚焦：页面加载完成后，输入框自动获得焦点，用户可直接输入指令，减少操作步骤；

- 上下文记忆：支持连续多轮对话，AI自动记忆上下文信息，无需用户重复输入，提升对话流畅度；

- 快捷检索：左侧功能栏支持对话搜索，输入关键词可快速定位历史对话，提升信息检索效率。

## 3\.2 流畅交互体验

- 过渡动画：添加轻微过渡效果，如输入框聚焦/失焦、消息发送/接收、侧边栏展开/收起等，提升交互质感，避免生硬跳转；

- 反馈提示：操作后及时给出反馈（如消息发送成功提示、文件上传进度、功能调用状态），让用户明确操作结果；

- 容错设计：输入框支持撤销/恢复，误操作可快速修正；删除对话时弹出确认提示，避免误删；文件上传失败时提供重试按钮。

## 3\.3 个性化与灵活性

- 个性化设置：支持浅色/深色模式切换、字体大小调整（小/中/大），适配不同用户视力需求和使用环境；

- 对话管理灵活：支持对话置顶、归档、自定义标签，用户可根据需求整理对话，提升使用效率；

- 功能可定制：常用工具可添加至快捷入口，不常用功能隐藏在更多菜单，兼顾便捷性与界面简洁性。

补充说明：本规范为通用设计框架，可根据产品定位、目标用户需求，灵活调整各区域比例、视觉风格及功能细节，核心是保证布局清晰、交互流畅、用户易用。
