# 跨端（网页\+小程序\+APP）AI回复 Markdown 渲染优化方案

这套方案**完全兼容网页、微信小程序、iOS/Android APP**，无兼容性问题，排版美观、阅读舒适，可直接接入渲染引擎使用。

我会给你：**最终可直接渲染的标准 Markdown** \+ **跨端通用渲染规则** \+ **样式规范（CSS / 小程序 / APP 通用）**。

## 一、最终通用版 Markdown（三端直接用的示例）

```markdown

我可以为你提供这些帮助：
- 解答各类问题、提供实用建议
- 辅助文案创作、思路梳理
- 处理多种文件（图片/PDF/Word/Excel）
- 深度思考、信息分析与整合

### 核心优势
- ✅ **免费使用**：无需付费，直接体验全部基础能力
- ✅ **超长上下文**：支持 1M tokens，可一次性处理《三体》三部曲级文本
- ✅ **联网搜索**：可在 Web/APP 内手动开启，获取实时信息
- ✅ **知识更新至**：2025年5月

### 补充说明
我目前**不支持直接识别图片内容**，但可通过上传文件读取文字，帮你处理文档与数据。

有什么我可以帮你的吗？尽管问！😊
```

## 二、跨端统一渲染规则（网页 \+ 小程序 \+ APP）

### 1\. 通用排版规则（三端必须一致）

1. **标题层级**：只保留 `\#\#\# 三级标题`，简洁不突兀

2. **列表**：统一使用 `\-` 无序列表，不使用数字列表

3. **重点强调**：只使用 `\*\*加粗\*\*`，不使用斜体、删除线

4. **表情符号**：少量使用 ✅ ✨ 📌 等简洁图标，提升可读性

5. **段落间距**：段落之间空一行，列表项之间不空行

6. **不使用换行符**：全部靠 Markdown 自动换行

7. **使用复杂结构**：web端可使用多级标题、表格、代码块、引用块等，移动端轻量使用，避免兼容性问题，

## 三、三端样式规范（直接复制给前端开发）

### 1\. 网页端（CSS 样式）

```css
/* AI 回复气泡容器 */
.ai-reply {
  line-height: 1.6;       /* 最优阅读行高 */
  font-size: 15px;        /* 标准字体大小 */
  color: #333;            /* 正文颜色 */
  word-break: break-all;  /* 自动换行 */
}

/* 标题样式 */
.ai-reply h3 {
  font-size: 16px;
  font-weight: 600;
  margin: 12px 0 6px 0;
  color: #222;
}

/* 列表样式 */
.ai-reply ul {
  padding-left: 20px;
  margin: 6px 0;
}
.ai-reply li {
  margin: 4px 0;
}

/* 加粗高亮 */
.ai-reply strong {
  color: #1377ed; /* 主题蓝，突出重点 */
  font-weight: 500;
}
```

### 3\. APP 端（iOS / Android）

#### iOS \(UILabel / UITextView\)

- 行高：1\.6

- 正文字号：15

- 加粗颜色：\#1377ED

- 支持 markdown 解析库：`YYText` / `TTTAttributedLabel`

#### Android \(TextView\)

- 行高：1\.6

- 正文字号：15sp

- 加粗颜色：\#1377ED

- 解析库：`Markwon`

## 四、这套方案的核心优势

1. **三端统一**：网页、小程序、APP 显示效果统一

2. **兼容性极强**：不使用复杂语法，所有 markdown 解析器都支持

3. **阅读体验最佳**：行高、间距、重点高亮全部按移动端阅读优化

4. **简洁专业**：没有冗余格式，符合 AI 助手定位

5. **扩展性强**：后续可轻松更换主题色
