## 如何查看小程序和 App 的样式

### 一、微信小程序

**前置条件**：安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)

**运行方式**：

1. 打开微信开发者工具
2. 点击「导入项目」，选择目录：
   ```
   c:\Users\Administrator\Desktop\IAC-incubator\miniapp
   ```
3. 导入后即可在模拟器中预览小程序样式

> ⚠️ 注意：首次导入时可能需要配置 AppID（可选择测试号）

---

### 二、React Native App (Expo)

**前置条件**：已安装 Node.js

**运行方式**：

```bash
# 进入 app 目录
cd c:\Users\Administrator\Desktop\IAC-incubator\app

# 安装依赖
npm install

# 启动开发服务器
npm start
```

启动后会自动打开浏览器或 Expo Go 客户端，可选择：
- **Android 模拟器** — 需要安装 Android Studio
- **iOS 模拟器** — 需要 macOS + Xcode
- **手机扫码** — 手机安装 Expo Go App 后扫码

---

### 三、Web 前端 (React + Vite)

**运行方式**：

```bash
# 进入 frontend 目录
cd c:\Users\Administrator\Desktop\IAC-incubator\frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

启动后访问 `http://localhost:5173` 可查看网页版样式

---

### 四、后端服务（可选）

如果需要完整功能，还需要启动后端：

```bash
# 进入 backend 目录
cd c:\Users\Administrator\Desktop\IAC-incubator\backend

# 安装依赖
npm install

# 启动开发服务器
npm run start:dev
```

后端运行在 `http://localhost:3000`

---

### 快速启动脚本

你也可以创建一个启动脚本一次性运行多个服务：

```powershell

Start-Process -FilePath "npm" -ArgumentList "run","dev" -WorkingDirectory "c:\Users\Administrator\Desktop\IAC-incubator\frontend"
Start-Process -FilePath "npm" -ArgumentList "start" -WorkingDirectory "c:\Users\Administrator\Desktop\IAC-incubator\app"
```
