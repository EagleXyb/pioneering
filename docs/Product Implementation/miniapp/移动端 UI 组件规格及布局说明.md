# 移动端 UI 组件规格及布局说明（2023 年 10 月 1 日）

## 一、整体结构与布局规范

### 1\. 页面层级结构

整体为移动端标准「顶部导航 \+ 主内容区」的纵向层级结构，布局遵循从上到下的顺序：

1. 顶部导航栏

2. 搜索栏

3. 精选模块区

4. 标签导航栏

5. 推荐列表区

### 2\. 页面基础规范

- 适配：移动端竖屏布局，采用「安全区适配」设计，顶部状态栏、底部均预留安全边距

- 背景：页面整体背景为浅灰色（\#F5F5F5 级别），内容卡片为白色背景

- 间距：所有模块之间、模块内元素之间均采用统一的 16px/8px 间距规范

## 二、各模块详细样式与布局

### 1\. 顶部导航栏

- 布局：水平弹性布局，高度固定（约 56px）

- 元素分布：

    - 左侧：返回箭头图标（点击可返回上一级）

    - 中间：页面标题，居中显示

    - 右侧：用户中心图标（圆形 / 人形图标）

- 样式：背景为纯白色，元素垂直居中对齐

### 2\. 搜索栏

- 位置：顶部导航栏下方，全宽显示

- 样式：圆角矩形输入框，浅灰色背景，左侧内置搜索图标，无外边框

- 交互：点击可唤起搜索输入状态，支持输入文字搜索

### 3\. 精选模块区

- 布局：纵向列表布局，模块标题与「换一换」按钮水平分布

- 模块标题区：

    - 左侧：“精选” 文字，加粗字体

    - 右侧：「换一换」按钮（带刷新图标 \+ 文字），点击可刷新精选内容

- 内容列表：

    - 布局：纵向排列的卡片列表，每个卡片为独立容器，卡片之间有 12px 间距

    - 卡片结构（单条）：

        - 左侧：方形图标（圆角处理，尺寸固定，约 80x80px）

        - 右侧：文字信息区，垂直弹性布局，从上到下依次为标题、描述、订阅 / 内容 / 作者信息

        - 右侧末尾：黄色认证标识（对勾样式）

    - 卡片样式：白色背景，圆角（8px\-12px），轻微阴影 / 分割线区分边界，全宽占比，左右预留内边距

### 4\. 标签导航栏

- 布局：水平滚动标签栏，支持横向滑动

- 样式：

    - 标签项：文字标签，默认状态为浅灰色文字，选中状态为黑色加粗文字（当前选中为 “推荐”）

    - 分布：标签项均匀分布，超出屏幕宽度可横向滚动

- 交互：点击标签可切换下方列表内容，实现分类筛选

### 5\. 推荐列表区

- 布局：纵向列表布局，卡片样式与精选模块的卡片完全一致，保持设计统一性

- 卡片结构：与精选卡片复用同一套组件，仅内容不同

- 加载逻辑：列表支持无限滚动加载，可向下滑动加载更多内容

## 三、交互与动效规范

1. 点击交互：

    - 所有可点击元素（返回、搜索、换一换、标签、卡片、用户图标）均有点击反馈（颜色变化 / 缩放动效）

    - 卡片点击后进入对应的知识库详情页

2. 滚动交互：

    - 标签栏支持横向滚动

    - 主列表支持纵向滚动，顶部导航栏可固定

3. 刷新交互：

    - 「换一换」按钮点击后，精选模块的卡片会进行刷新替换，配合轻微的加载动效

## 四、视觉与设计规范

1. 色彩规范：

    - 主色调：无强品牌色，以黑白灰为主，仅认证标识使用黄色作为强调色

    - 背景色：页面背景浅灰，卡片背景纯白，形成层级区分

2. 字体规范：

    - 标题：加粗，字号较大

    - 描述文字：常规字重，字号较小，浅灰色

    - 辅助信息（订阅 / 内容数）：字号最小，浅灰色

3. 图标规范：

    - 线性图标（返回、搜索、用户、刷新），线条粗细统一

    - 卡片左侧图标为方形圆角，风格多样但尺寸统一

4. 间距与尺寸：

    - 模块间距：统一 24px

    - 卡片内边距：上下 16px，左右 16px

    - 卡片内元素间距：图标与文字间距 12px，文字行间距 8px

## 五、可开发实现要点

1. 组件复用：精选卡片与推荐卡片复用同一组件，通过传入不同数据渲染，保证样式一致性

3. 滚动性能优化：长列表使用虚拟列表 / 懒加载，优化滚动性能
