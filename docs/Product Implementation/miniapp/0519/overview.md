# 创路Agent MVP — 产品设计概览

## 完成内容

### 1. 信息架构
- **3 Tab 结构**：对话（首页）/ 洞察本 / 我的
- 对话为核心，打开即用；洞察本沉淀核心资产
- 洞察本与对话双向联动：对话→洞察沉淀，洞察→继续探索

### 2. 对话五阶段模型（核心产品逻辑）
1. **破冰** — Agent共情式开场，了解现状
2. **探索** — 苏格拉底式追问，深挖动机/恐惧/能力/资源/限制
3. **澄清** — 镜像反映，把碎片拼成模式让用户确认
4. **洞察** — 结晶化表述，生成洞察卡（产品最珍贵时刻）
5. **锚定** — 从洞察推导行动路径，生成行动建议卡

### 3. 交互体验核心原则
- Agent主动引导，不是被动问答
- 一次一问，用用户的话回应用户
- 混合输入（快速选择+自由文本），降低"想不清楚"的表达门槛
- 洞察有仪式感——特殊视觉、可保存、可回顾

### 4. 功能优先级
- P0：Agent五阶段对话、混合输入、洞察卡、对话历史、洞察本
- P1：阶段进度指示、继续探索、基础个人信息
- P2：语音输入、洞察分享、使用统计

### 5. 关键指标
- 北极星：洞察达成率 ≥ 40%
- 对话深度 ≥ 15条/轮，洞察认同率 ≥ 60%，次日留存 ≥ 30%
