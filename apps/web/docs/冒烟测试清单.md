# web 端冒烟测试清单（UI 栈对齐重写期间每阶段必跑）

> 来源：`outputs/web-UI栈对齐desktop重写方案-2026-10-05.md` P0-0.5
> 触发时机：每个阶段（P0→P4）退出前；门禁顺序 `lint → typecheck → test → build` 全绿后执行人工冒烟。
> 前置：后端已启动（vite 代理 `/api → http://localhost:8088`），`npm run dev` 打开 http://localhost:5173

## ① chat 模式全流程
- [ ] 登录成功进入 /chat
- [ ] 发送消息：气泡上屏、流式逐字输出、状态指示正常
- [ ] 流式中点击「停止」：请求中止、停止后界面可继续输入
- [ ] 「重新生成」：替换原回答并重新流式
- [ ] 反馈（good/bad）：状态提交成功、按钮态正确
- [ ] 无标题会话首轮对话后生成 AI 标题（两阶段：临时标题 → 后端标题）

## ② 会话管理
- [ ] 切换历史会话：消息区正确加载、不串会话
- [ ] 历史列表分页：滚动到底部自动加载更多
- [ ] 新建会话：空白输入态、activeId 切换正确
- [ ] 归档 / 从归档恢复 / 删除（含确认弹框）：列表即时更新

## ③ task 模式（Plan-and-Execute）
- [ ] /task 发送任务：时间轴逐步渲染（pending/running/done 状态样式）
- [ ] 流式中断与错误态展示
- [ ] 回答中的 html/svg 代码块出现「预览」按钮，点击打开 artifact 预览
- [ ] 左右分栏拖拽 resize 可用

## ④ 设置
- [ ] 打开设置弹框：切换亮色/暗色主题即时生效，刷新后保持
- [ ] 字号 / 密度设置生效
- [ ] 保存后 localStorage 值与界面一致

## ⑤ 静态页与异常态
- [ ] /help 帮助页正常打开与关闭
- [ ] 访问不存在路径展示 404 页
- [ ] 未登录访问受保护路由跳转登录页
- [ ] （阶段 2 起抽查）亮/暗主题双态、移动端窄屏断点布局
