# 单站融合下的信息架构与导航设计

> 版本：V1.0　日期：2026-09-24
> 前置：《认知创新品牌网站与产品转化完整方案》
> 约束：**单站融合，一个域名**；产品形态为「智能体 + 知识库 + 学习资料」
> 本文为可直接交付给设计与前端的架构定稿。文中 `/agent/` 为产品路径代称，落地时替换为产品名或实际路径。

## 结论先行：导航定稿

### 主导航（6 项，含首页）

```
首页 │ 认知理念 │ 知识专栏 │ 智能体 │ 案例 │ 关于我们
                                              [🔍] [免费体验 →]
```

| # | 导航项 | 路径 | 承担的任务 |
|---|---|---|---|
| 1 | 首页 | `/` | 30 秒说清主张，分发流量 |
| 2 | 认知理念 | `/cognition/` | **品牌内核**，全站专业度锚点 |
| 3 | 知识专栏 | `/insights/` | 内容资产，长期 SEO 引擎 |
| 4 | **智能体** | `/agent/` | **转化主链路**，产品即方法论的执行体 |
| 5 | 案例 | `/cases/` | 信任证明，品牌与产品共用 |
| 6 | 关于我们 | `/about/` | 人格化信任 + 线索收集（联系表单并入） |

顶部右侧：**搜索图标 + 「免费体验」主 CTA 按钮**（不再是"订阅"）。

### 四个关键决策

| 决策 | 内容 | 理由 |
|---|---|---|
| **① 做减法：砍掉独立的「课程与服务」** | 学习资料降为 `/agent/learn/`，企业咨询降为 `/agent/enterprise/` | 智能体形态下产品是主体，学习资料是上手路径与深度延伸。原栏目若保留一级，会让用户以为你在卖课、AI 是赠品 |
| **② 案例保持一级，不并入产品** | 独立 `/cases/` | 案例同时服务于品牌可信度与产品转化；并入产品会削弱品牌侧的说服力 |
| **③ 全站右下角常驻智能体悬浮入口** | 除产品页外全站可见 | **最重要的导航决策**。把「读内容」到「用产品」压缩到一次点击，且不需离开当前页 |
| **④ CTA 从「订阅」改为「免费体验」** | 顶部右侧主按钮 | 产品的体验门槛为零，体验本身就是最强的转化动作，优先级高于留资 |

## 一、设计原则

### 1.1 从"品牌栏目"转向"用户任务"

原方案的导航是按品牌有什么来组织的（理念、专栏、课程、案例、关于）。加入产品后如果直接并列，会变成 7 项超载，而且用户看不出该点哪个。

**重构依据：用户来这个站只有四种意图。**

| 用户意图 | 心里的问题 | 导航承接 |
|---|---|---|
| 想了解这套方法 | "你到底主张什么" | 认知理念 |
| 想读点东西 | "有没有值得看的内容" | 知识专栏 |
| **想用它解决我的问题** | "这东西能帮我干什么" | **智能体** |
| 想判断你靠不靠谱 | "凭什么信你" | 案例 + 关于我们 |

**四项意图对应四个一级栏目，首页与关于我们各承担分发与收口。这就是 6 项的来源。**

### 1.2 三条不可违背的规则

1. **产品不能藏在二级。** 它是转化主链路，必须是一级导航；藏起来等于放弃自有流量转化。
2. **内容不能被降格为营销。** 知识专栏保持一级，且**不做产品导流改造**（除文末与文中的软入口），保住品牌的"有据"调性。
3. **单域名内所有页面共享一套设计系统与埋点。** 这是单站融合相对双站分治的核心优势，不要在实现时拆成两套模板。

## 三、主导航详细定义

### 3.1 顶部导航结构

```
┌────────────────────────────────────────────────────────────────────┐
│  LOGO        首页  认知理念  知识专栏  智能体  案例  关于我们   🔍 [免费体验]  │
└────────────────────────────────────────────────────────────────────┘
```

| 元素 | 规范 |
|---|---|
| 位置 | 桌面端吸顶（sticky），滚动时压缩高度并加 1px 细线 |
| 首页导航样式 | 首屏可为透明底，滚动后转白底；内页统一白底 |
| 当前项标识 | 2px 点缀色下划线，不用色块填充 |
| 主 CTA | 实心点缀色按钮，文案「免费体验」；hover 时轻微上移 2px |
| 搜索 | 图标入口，点击展开全屏搜索浮层（支持文章、概念、案例） |
| **悬浮体验入口** | 右下角常驻，除 `/agent/` 下所有页面外均显示（见第五节） |

### 3.2 导航项命名规范

- 字数控制在 **2-4 字**，统一为名词或名词短语（首页、认知理念、知识专栏、智能体、案例、关于我们）
- 全站中文，**禁止中英混排**作为导航文案（如不要写"Insights 专栏"）
- 「智能体」为代称，产品正式命名后直接用**产品名**替换，比通用词更有辨识度
- 不要使用「产品」「解决方案」这类无信息量的词——它们回答不了用户"这到底是什么"

### 3.3 二级导航（子导航条）

只有两个栏目需要横向子导航：

| 栏目 | 子导航项 | 说明 |
|---|---|---|
| **认知理念** | 模型 / 三大支柱 / 概念库 / 方法与来源 | 5 项，帮助用户在方法论内部跳转 |
| **智能体** | 体验 / 能力 / 样例 / 学习资料 / 定价 | 5 项；企业版与 FAQ 收在页内锚点 |

其他栏目用面包屑即可，不设子导航——**每多一层导航就多一层决策成本**。

## 四、各栏目的定位与内容要点

### 4.1 首页 `/`

导航的分发中枢。**新增一处：产品体验区必须在前 3 屏内出现**（原方案放在 S6，往前移到 S4 之后）。

| 屏序 | 板块 | 相对原方案的调整 |
|---|---|---|
| S1 | 首屏 Hero | 主 CTA 改为「免费体验智能体」，次 CTA「了解认知理念」 |
| S2 | 品牌速览 | 不变 |
| S3 | 痛点共鸣 | 不变，每张卡的"我们的回答"链接到对应能力 |
| **S4** | **核心理念** | 不变（模型图分步点亮） |
| **S5** | **智能体体验（新增，前移）** | 3 个能力入口 + 1 个样例对话预览 |
| S6 | 精选专栏 | 不变 |
| S7 | 案例与成果 | 不变 |
| S8 | 用户证言 | 证言改为侧重"用它解决了什么" |
| S9 | 品牌动态 | 不变 |
| S10 | 页脚 | 订阅区保留（与体验入口并存，不冲突） |

### 4.2 认知理念 `/cognition/`

品牌内核，投入优先级最高。**新增要求：每个概念与支柱都要有"用智能体试这一步"的入口**——因为智能体的能力映射就来自这里。

`/cognition/concepts/` 概念卡片库尤其重要：它既是长尾 SEO 承接页，也是**知识库的前端化呈现**（用户看到的和你喂给智能体的是同一套东西，这本身就是可信度证明）。

### 4.3 知识专栏 `/insights/`

保持一级，**不做产品化改造**。它是品牌的资产库与 SEO 引擎，不是产品导流页。

唯一的产品入口是文章内的对话窗（L1 软植入）与文末场景入口（L2），严格遵守第三篇的四级 CTA 梯度：**文章页只做 L1-L2，绝不出现 L4 硬转化。**

### 4.4 智能体 `/agent/`

转化主链路。**产品总览页首屏必须呼应 `/cognition/model/` 的模型图**，让用户一眼看到"这就是那套方法的执行体"。

| 页面 | 关键内容要求 |
|---|---|
| `/agent/` | 定位「不替你下判断，让你看清自己怎么下判断」；首屏放一段真实对话演示（静态或轻量可交互） |
| `/agent/try/` | 免注册 3-5 轮；留资时机在"要不要我记住你的项目上下文" |
| `/agent/capabilities/` | **能力 × 方法论映射表**（对应第 22 章的映射机制），每项能力挂对应文章链接 |
| `/agent/samples/` | 真实对话记录（脱敏），按场景分类——**这是最好的产品说明书** |
| `/agent/learn/` | 上手指南（3-5 分钟）/ 方法课程 / 练习清单；明确它是产品的配套，不是主售卖物 |
| `/agent/pricing/` | 价格透明，每个档位写清"你能得到什么产出" |
| `/agent/enterprise/` | 团队版 / 企业版，含定制知识库、私有部署选项、索取方案表单 |

**子导航必备 5 项**：体验 / 能力 / 样例 / 学习资料 / 定价。

### 4.5 案例 `/cases/`

独立一级。案例详情页在 STAR 结构之外，**必须挂两个入口**：

- 「用智能体复现这个分析 →」（导向 `/agent/try/`，预置该案例的场景）
- 「这个方法的方法论出处 →」（导向 `/cognition/` 对应章节）

### 4.6 关于我们 `/about/`

联系表单并入此栏目（`/about/contact/`），不单列一级，与总方案一致。

## 五、全局固定元素

### 5.1 悬浮智能体入口（★ 最关键）

| 项 | 规范 |
|---|---|
| 位置 | 右下角，距边缘 24px（移动端 16px） |
| 形态 | 收起时为圆形按钮（56px）；展开为对话面板（桌面 400×600，移动全屏抽屉） |
| 显示范围 | **全站除 `/agent/` 下所有页面外均显示**（产品页内已有完整入口，重复会干扰） |
| 首次出现 | 滚动到文章 30% 或停留 20 秒后，轻微展开一次提示气泡，仅一次，可关闭 |
| 预置提问 | **根据所在页面动态变化**——在概念卡页面预置"这个概念怎么用"，在案例页预置"分析我的类似场景" |
| 免注册 | 3-5 轮对话无需登录，第 6 轮或点击"保存上下文"时引导留资 |

**为什么这是最重要的决策：** 它把转化路径从"读完 → 找导航 → 进产品页 → 注册 → 体验"压缩成"读着 → 点一下 → 就在聊"。用户的信任在刚读完内容时最强，这个入口让体验发生在那个时刻。

### 5.2 顶部 CTA 与移动端底部条

| 端 | 形态 |
|---|---|
| 桌面 | 顶部导航右侧实心按钮「免费体验」 |
| 移动 | 顶部折叠为汉堡菜单；**底部常驻 CTA 条**「免费体验智能体 →」，高 56px，向上滚动时隐藏、向下滚动时显示 |

### 5.3 订阅入口的位置

订阅不占主导航，放在三处：**首页 S10、文章文末、页脚**。它和体验入口并存不冲突——体验是立刻用，订阅是长期关系。

## 六、URL 与面包屑规范

### 6.1 URL 规则

| 规则 | 说明 |
|---|---|
| 结构 | 小写英文 + 连字符，层级不超过三级：`/insights/{category}/{slug}/` |
| 产品路径 | 建议直接用**产品名**（如 `/hermes/`），其次 `/agent/`；避免 `/product/` 这类无辨识度的词 |
| 文章 URL | 用「分类 + 语义化短标题」，**不用 ID 与日期**，便于长期 SEO 与分享 |
| 未来拆站预留 | `/agent/` 下所有页面自成一棵子树，未来迁到独立域名时路径可整体平移，无需重构 |

### 6.2 面包屑

全站统一，层级不超过三级：

```
首页 > 知识专栏 > 认知科学 > 当前文章
首页 > 智能体 > 学习资料
首页 > 案例 > 某新能源企业创新工作坊
```

面包屑需同时输出 `BreadcrumbList` 结构化数据。

## 七、页脚结构

页脚是二级导航的兜底，也是 SEO 内链的重要出口。

| 列 | 内容 |
|---|---|
| 列 1 · 品牌 | LOGO、一句话定位、社交图标（公众号 / 视频号 / X） |
| 列 2 · 认知 | 认知模型、三大支柱、概念卡片库、方法与来源 |
| 列 3 · 内容 | 认知科学、思维方法、创新实践、组织进化、专题合集 |
| 列 4 · 产品 | 免费体验、能力总览、对话样例、学习资料、定价、企业版 |
| 列 5 · 关于 | 品牌故事、团队、合作与背书、联系我们、加入我们 |
| 底栏 | 备案号、隐私政策、用户协议、站点地图、版权年份 |

**列 4「产品」是新增的**，其余沿用原方案。

| **认知理念** | — | ○ 延伸阅读 | ★每个概念挂体验入口 | ○ | ○ |
| **知识专栏** | ○ 文中内链 | — | ★文内对话窗（L1）+ 文末（L2） | ○ | ○ 作者页 |
| **智能体** | ★能力页反向引用 | ○ 对应文章 | — | ★样例与证言 | ○ 企业版 |
| **案例** | ★方法论出处 | ○ | ★复现入口 | — | ○ |
| **关于我们** | ★ | ○ | ★ | ★ | — |

★ = 强入口（显眼位置、视觉强化）　○ = 弱入口（文字链或页脚）

**三条硬规则：**

1. **任何页面都不出现"死胡同"**——每个页面至少有一个明确的下一步。
2. **文章页的产品入口是软的**（对话窗、预置提问），不出现价格与购买按钮。
3. **产品页必须能回到方法论**——否则用户不知道你的智能体"凭什么这么回答"，信任建立不起来。

## 十、与原方案的变更对照

| 项 | 原方案（纯品牌站） | 本方案（单站融合） | 变更原因 |
|---|---|---|---|
| 一级导航数 | 6 项 | 6 项 | 数量不变，但内容替换 |
| 「课程与服务」 | 一级栏目 | **取消一级** → `/agent/learn/` + `/agent/enterprise/` | 智能体是主体，学习资料是配套 |
| 「智能体」 | 无 | **新增一级** | 转化主链路不能藏 |
| 顶部 CTA | 订阅 / 预约咨询 | **免费体验** | 体验门槛为零，转化优先级高于留资 |
| 首页产品板块 | 原 S6 | **前移至 S5** | 缩短"了解品牌 → 体验产品"的距离 |
| 全局悬浮入口 | 无 | **新增，全站常驻** | 最重要的一次点击压缩 |
| 页脚 | 5 列（无产品列） | **新增「产品」列** | 兜底导航需覆盖产品全部页面 |
| 案例页 | 独立一级 | 独立一级（+ 复现入口） | 保持，新增产品互链 |
| URL 根路径 | 无产品分支 | `/agent/` 自成子树 | 为未来拆站预留平移可能 |
