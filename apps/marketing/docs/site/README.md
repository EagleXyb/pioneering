# 认知 × 创新 品牌站 · HTML 初稿

单站融合（一个域名）· 6 个页面 · V1.0

## 预览

直接用浏览器打开 `index.html` 即可，无需构建工具、无外部依赖、无 CDN。

## 文件结构

```
site/
├── assets/style.css      设计系统（色彩 / 字阶 / 间距 / 组件 / 响应式）
├── index.html            首页（S1–S10 十屏）
├── cognition.html        认知理念（模型 · 三大支柱 · 概念库 · 来源 · FAQ）
├── insights.html         知识专栏（列表 · 专题 · 文章详情含内嵌对话窗）
├── agent.html            智能体（定位 · 能力映射 · 样例 · 体验 · 学习资料 · 定价）
├── cases.html            案例（列表 + STAR 详情）
└── about.html            关于我们（故事 · 团队 · 背书 · 联系表单）
```

## 已实现的关键设计

| 项 | 落地情况 |
|---|---|
| 6 项主导航 | 首页 / 认知理念 / 知识专栏 / 智能体 / 案例 / 关于我们；「智能体」带 Active 下划线 |
| 顶部 CTA | 「免费体验」，移动端汉堡菜单 + 底部常驻 CTA 条 |
| 全局悬浮智能体入口 | 右下角常驻，点击展开对话面板；**agent.html 内不显示**（避免重复干扰） |
| 对话面板演示 | 展示「先问后答 + 知识溯源 + 反问收尾」三个产品行为 |
| 文章内嵌入口 | insights.html 文章内两处 inline-agent（L1 就地体验 / L2 场景延伸），无价格与购买按钮 |
| 渐变使用边界 | 仅首页 Hero 与证言区两处渐变，其余全部实底克制路线 |
| 响应式 | 断点 1000 / 900 / 768 / 600；移动端底部 CTA 条 + 悬浮入口上移避让 |
| 无障碍 | 支持 prefers-reduced-motion；卡片整块可点击；表单均带 label |
