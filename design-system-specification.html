B 端后台管理系统
可视化设计规范 v1.0

基于 Ant Design 设计理念，适配 React 19 + TypeScript 5.7 + Tailwind CSS 4 + shadcn/ui 技术栈。 覆盖 Design Token、图标系统、图表规范、核心组件、页面模板及无障碍设计。

适用范围

本规范适用于 Pioneering 项目所有前端页面的 UI 设计与开发工作。所有组件、图标、图表及页面布局均应遵循此规范，确保视觉一致性与可维护性。参考 Ant Design 设计语言 Research-backed。

1. 命名规范

所有 Design Token 采用 kebab-case 命名，兼容 CSS Custom Properties、JavaScript 对象键名及 Figma Variable 命名 Research-backed。

Token 类别命名模式示例
颜色（视觉层）color-{role}-{shade}color-primary-500, color-neutral-100
颜色（语义层）color-{semantic-role}color-brand, color-text-primary
间距spacing-{size}spacing-xs, spacing-md, spacing-xl
字体族font-family-{role}font-family-sans, font-family-mono
字号font-size-{scale}font-size-sm, font-size-lg
字重font-weight-{name}font-weight-regular, font-weight-bold
行高font-lineHeight-{scale}font-lineHeight-tight, font-lineHeight-normal
圆角radius-{size}radius-sm, radius-lg, radius-full
阴影shadow-{level}shadow-sm, shadow-lg
动效时长motion-duration-{speed}motion-duration-fast, motion-duration-slow
动效曲线motion-easing-{name}motion-easing-ease-out, motion-easing-spring
Z-indexz-index-{layer}z-index-dropdown, z-index-modal
规则：Token 名称必须同时是合法的 CSS Custom Property 名称（-- 前缀后）和合法的 JavaScript 对象键名。禁止空格、特殊字符（除连字符外）、保留字。

9.5 无障碍要求

要求规范
颜色对比度相邻系列色须 ≥ 3:1 对比度（WCAG 1.4.11 非文本对比度）
色盲友好不单独依赖颜色区分 — 使用图案、标签或直接标注作为冗余提示
屏幕阅读器每个图表须有 aria-label 总结图表类型和关键发现；提供数据表格作为替代视图
键盘操作图例项可聚焦，可通过键盘（Enter）切换
推荐库：本项目使用 Recharts 或 @ant-design/charts。图表组件应封装为 <ChartContainer> 通用容器，统一处理 Tooltip、Legend 和响应式适配。

12.3 切换逻辑

使用 data-theme 属性驱动主题切换。Tailwind CSS 4 环境下，通过 darkMode: 'selector' 实现与 .dark 类的绑定。

// React 主题切换 Hook
function useTheme() {
  const [theme, setTheme] = useState<'light' | 'dark'>(
    () => (localStorage.getItem('theme') as 'light' | 'dark') || 'light'
  );

  useEffect(() => {
    document.documentElement.setAttribute('data-theme', theme);
    document.documentElement.classList.toggle('dark', theme === 'dark');
    localStorage.setItem('theme', theme);
  }, [theme]);

  return { theme, toggle: () => setTheme(t => t === 'light' ? 'dark' : 'light') };
}
